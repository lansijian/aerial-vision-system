比赛环境说明
1.gazebo环境需要在比赛主机的docker上启动。各队把带有自己算法docker拷贝到主机即可。
2.在拷贝docker后使用以下命令进行载入
docker load -i package.tar
3.从镜像中启动容器
docker run -it \
  --name container_name \
  --gpus all \
  --env="DISPLAY" \
  --env="QT_X11_NO_MITSHM=1" \
  --env="NVIDIA_DRIVER_CAPABILITIES=all" \
  --volume="/tmp/.X11-unix:/tmp/.X11-unix:rw" \
  --volume="$HOME/.Xauthority:/root/.Xauthority:rw" \
  --network=host \
  images_name:tag
4.在创建的容器中启动算法，各队在自己的算法中无需启动gazebo
