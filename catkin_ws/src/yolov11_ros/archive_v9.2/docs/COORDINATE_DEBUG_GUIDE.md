## 🔍 问题诊断流程

### 1. 坐标系理解
- **MAVROS坐标系**: ENU (东-北-天)，原点在无人机起飞位置
- **Gazebo世界坐标系**: 原点在世界中心(0,0,0)
- **Body坐标系**: FLU (前-左-上)，与MAVROS对齐

### 2. 关键转换
```
世界坐标 = ENU坐标 + 起飞位置偏移
```

### 3. 无人机起飞位置
- typhoon_h480_0: (0, -5, 1)
- typhoon_h480_1: (0, 5, 1)

### 4. Actor真实位置（世界坐标）

- actor_1 (BLUE): (-20.2, -40.8)
- actor_2 (BROWN): (-41.3, -5.2)

## ⚠️ 常见问题

### 问题1: 坐标误差超过30米
**原因**: 相机到Body坐标系转换矩阵错误  
**解决**: 确保使用FLU坐标系，不是FRD
```python
R_cam_base = np.array([
    [0, 0, 1],   # Body X = 相机Z (前)
    [-1, 0, 0],  # Body Y = -相机X (左 = -右)
    [0, -1, 0]   # Body Z = -相机Y (上 = -下)
])
```

### 问题2: 射线不向下
**原因**: 云台角度设置不正确或旋转矩阵错误  
**解决**: 确认云台俯仰角为-45度，Pitch旋转矩阵正确

### 问题3: 相机内参影响
**原因**: 焦距参数不准确  
**解决**: 
- 640x360分辨率，FOV=60度时，fx≈530
- 可通过launch文件参数调整：`<param name="fx" value="530.0"/>`
