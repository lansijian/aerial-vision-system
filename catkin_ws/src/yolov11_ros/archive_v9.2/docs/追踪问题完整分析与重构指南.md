## 🔍 追踪失败的根本原因分析

### 问题1: 接口不匹配（已修复）

#### waypoint_flight的期望
查看waypoint_flight.py源码（第76-77行）：
```python
self.tracking_status_sub = rospy.Subscriber(
    f'/drone_{self.drone_id}/human_tracker/status', Bool, ...)
self.tracking_control_sub = rospy.Subscriber(
    f'/drone_{self.drone_id}/human_tracker/cmd_vel', Twist, ...)
```

#### human_tracker之前的错误
```python
# v8.x和v9.0错误地发布到：
self.waypoint_pause_pub.publish(String(data="pause"))  # ❌ 错误话题
# 话题: /drone_0/waypoint_flight/pause
# waypoint_flight根本不订阅这个！

# v9.2修复后：
self.tracking_status_pub.publish(Bool(data=True))  # ✅ 正确话题
# 话题: /drone_0/human_tracker/status
```

**结论**: 之前waypoint_flight根本收不到追踪信号，所以一直在航点飞行模式！

---

### 问题2: waypoint_flight的控制逻辑

查看waypoint_flight.py源码（第589-637行）：

```python
# 主飞行循环（每20Hz执行）
time_since_tracking = current_time - self.last_tracking_control_time
actively_tracking = time_since_tracking < 1.5 and self.tracking_active

if actively_tracking:
    # ✅ 转发追踪速度到MAVROS
    if self.latest_tracking_cmd:
        target = PositionTarget()
        target.velocity.x = cmd.linear.x
        target.velocity.y = -cmd.linear.y
        target.velocity.z = -cmd.linear.z
        target.yaw_rate = -cmd.angular.z
        self.setpoint_pub.publish(target)  # 发布到MAVROS
else:
    # ❌ 发布航点控制到MAVROS
    control_cmd = self._waypoint_control()
    self.setpoint_pub.publish(control_cmd)
```

**关键条件**（必须同时满足）：
1. `self.tracking_active = True` ← 由`/drone_0/human_tracker/status`设置
2. `time_since_tracking < 1.5秒` ← 由`/drone_0/human_tracker/cmd_vel`更新
3. `self.latest_tracking_cmd != None`

**之前的问题**：
- tracking_status未正确发布 → `tracking_active = False`
- cmd_vel话题名称错误 → `time_since_tracking > 1.5`
- 导致`actively_tracking = False`
- waypoint_flight一直发布航点控制，不转发追踪速度

### 问题2: human_tracker发布频率不够

**human_tracker实际**: 
- tracking_loop是60Hz（正确）
- 但只在track_target()中发布速度

**潜在问题**: 检测不稳定时，可能超过1.5秒未更新

### 问题3: track_target()可能未被调用

**可能的竞态条件**:
- human_tracker先启动 → 发布status
- waypoint_flight后启动 → 错过了首次status

**优点**:

**实现**:

```python
# human_tracker.py中直接发布到MAVROS
self.setpoint_pub = rospy.Publisher(
    f'/{self.vehicle_ns}/mavros/setpoint_raw/local',
    PositionTarget, queue_size=1)

# 发布速度控制
def publish_cmd_vel(self, vx, vy, vz, yaw_rate):
    target = PositionTarget()
    target.coordinate_frame = PositionTarget.FRAME_BODY_NED
    target.type_mask = PositionTarget.IGNORE_PX + PositionTarget.IGNORE_PY + PositionTarget.IGNORE_PZ + ...
    target.velocity.x = vx
    target.velocity.y = vy
    target.velocity.z = vz
    target.yaw_rate = yaw_rate
    self.setpoint_pub.publish(target)
```
