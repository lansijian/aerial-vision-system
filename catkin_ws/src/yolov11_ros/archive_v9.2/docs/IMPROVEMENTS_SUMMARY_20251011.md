### 2. 坐标系统修复 ✅
**问题**: 发布的坐标与真实位置相差30-40米

**根本原因**:
- 相机到Body坐标系转换矩阵错误（错用FRD而非FLU）
- 未正确处理ENU坐标到世界坐标的转换
- 相机内参默认值不准确

**修复**:
```python
# 正确的相机到Body转换（FLU坐标系）
R_cam_base = np.array([
    [0, 0, 1],   # Body X = 相机Z (前)
    [-1, 0, 0],  # Body Y = -相机X (左 = -右)
    [0, -1, 0]   # Body Z = -相机Y (上 = -下)
])

# 世界坐标转换
target_world = target_enu + world_offset
# typhoon_h480_0: world_offset = (0, -5)
# typhoon_h480_1: world_offset = (0, 5)
```
