# v9.5.7 版本存档

## 存档日期
2025-10-13

## 版本说明
这是在发现坐标系统问题后的存档版本，准备进行重构。

## 主要问题
1. 无人机0的坐标转换误差达到30米
2. 坐标系偏移值设置不当
3. 航点配置可能导致无人机飞行到错误位置

## 存档文件
- human_tracker_v9.5.7.py - 人体追踪器（已包含坐标转换修复但仍有问题）
- multi_drone_system_v9.5.7.launch - 系统启动文件

## 技术特点
1. 修正了相机参数（cx=320.5, cy=180.5）
2. 实现了完整的坐标变换链
3. 添加了安全限制防止极端误差
4. 支持参数化配置

## 待解决问题

2. 航点文件配置需要验证

## 重构方向
