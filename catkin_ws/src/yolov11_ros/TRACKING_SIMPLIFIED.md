# 追踪算法简化优化文档

## 版本信息
- **版本**: v10.1.2-simplified
- **日期**: 2025-10-16
- **优化目标**: 保持YOLO检测框在图像中心

## 核心优化

### 1. 去除复杂逻辑 ❌

**删除的功能：**
- ❌ Kalman滤波器（100行代码）
- ❌ 积分控制项（Ki_yaw）
- ❌ 目标丢失后绕圈搜索
- ❌ 复杂的目标选择逻辑
- ❌ 多余的状态变量

**原因：**
- Kalman滤波增加延迟，影响实时性
- 积分项可能导致超调
- 绕圈搜索浪费时间，不如直接回航点
- 过度工程化，影响维护

### 2. 核心追踪算法 ✅

**控制策略（优先级排序）：**

#### 优先级1：横向对齐（偏航控制）
```python
# 目标：保持目标在图像中心（横向）
u_offset = u_center - cx  # 横向偏移（像素）

if abs(u_offset) < 15:
    yaw_rate = 0.0  # 死区：±15像素内认为已对齐
else:
    Kp_yaw = 100.0 / max(box_height, 20)  # 自适应增益
    yaw_rate = -Kp_yaw * u_offset
    
    # 边缘加速
    if abs(u_offset) > 250:
        yaw_rate *= 2.0  # 目标快出视野，紧急转向
```

**控制逻辑：**
- 主要靠**偏航（yaw）**对齐目标
- 自适应增益：目标越近转速越慢（避免超调）
- 边缘加速：目标快出视野时紧急转向

#### 优先级2：距离控制（前后速度）
```python
# 目标：保持理想距离（框高160像素 ≈ 3米）
height_error = 160 - box_height

forward_speed = 2.0 * (height_error / 160)  # Kp=2.0
forward_speed -= 0.002 * v_offset  # 纵向微调
```

**控制逻辑：**
- 框太小（距离远）→ 前进
- 框太大（距离近）→ 后退
- 纵向偏移微调：目标在下半区略后退

#### 优先级3：横向微调（辅助）
```python
# 目标：辅助横向对齐（主要靠偏航）
if abs(u_offset) < 10:
    lateral_speed = 0.0
else:
    lateral_speed = 0.001 * u_offset  # 小增益，避免抖动
```

**控制逻辑：**
- 小幅度横移，避免抖动
- 主要对齐靠偏航，横移只是辅助

#### 优先级4：高度保持
```python
vz = 0.0  # 交给PX4自动保持高度
```

### 3. 参数优化

| 参数 | v10.1.2 | v10.1.2-simplified | 说明 |
|------|---------|---------------------|------|
| `Kp_yaw_base` | 80.0 | **100.0** | 提高偏航响应速度 |
| `Ki_yaw` | 0.001 | **删除** | 去除积分项，避免超调 |
| `Kp_distance` | 1.5 | **2.0** | 提高距离控制响应 |
| `max_vy` | 1.0 | **0.8** | 降低横向速度（主要靠偏航） |
| `max_yaw_rate` | 0.5 | **0.6** | 提高最大偏航率 |
| `use_kalman` | True | **删除** | 去除Kalman滤波 |

### 4. 目标丢失策略

**v10.1.2（复杂）：**
```python
lost_count > 30  # 1秒无检测（30帧@30Hz）
→ 可能绕圈搜索？
```

**v10.1.2-simplified（简洁）：**
```python
lost_count > 15  # 0.5秒无检测（15帧@30Hz）
→ 立即恢复航点模式
```

**优势：**
- 快速决策，不浪费时间
- 回到航点继续搜索其他目标
- 避免复杂的搜索逻辑

## 使用建议

### 参数调优
如果追踪效果不理想，可调整以下参数：

```yaml
# 偏航控制（最重要）
Kp_yaw_base: 100.0      # 增大 → 转得更快，减小 → 转得更慢
max_yaw_rate: 0.6       # 增大 → 最大转速更高

# 距离控制
Kp_distance: 2.0        # 增大 → 前后运动更快
ideal_box_height: 160   # 调整理想距离（框高160px ≈ 3米）

# 速度限制
max_vx: 3.0            # 前后最大速度
max_vy: 0.8            # 横向最大速度（建议保持小值）
```

### 调试建议
观察日志输出：
```
[中心追踪] 偏移:(u=+50, v=-10) 框高:140(目标160) | 速度:(前+0.35, 右+0.05, 转-0.25)
```

**判断标准：**
- `u_offset`应趋向0（横向居中）
- `box_height`应趋向160（距离合适）
- 速度应平滑变化，无剧烈抖动
