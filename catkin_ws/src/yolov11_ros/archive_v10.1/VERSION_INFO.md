# v10.1 版本信息

## 版本概要
- **版本号**: v10.1.0
- **发布日期**: 2025-10-14
- **版本类型**: 性能优化版本
- **代码名称**: Precision Enhancement
- **开发团队**: 东华大学 Astraeus队

## 版本目标

基于v10.0.1修复颜色映射问题后，v10.1专注于提升坐标精度，目标是将误差从2米降低到1米以内，完全满足官方比赛要求。

## 核心技术栈

### 1. 卡尔曼滤波器（Kalman Filter）
- **状态向量**: [x, y, vx, vy]
- **预测模型**: 恒速运动模型
- **更新频率**: 30Hz
- **优势**: 平滑噪声，预测位置，处理短暂丢失

### 2. 自适应相机标定
- **动态参数**: fx, fy (焦距)
- **学习率**: 0.001
- **反馈机制**: 基于误差历史
- **参数历史**: 10帧回滚缓存

### 3. 多层深度估计
```python
深度融合权重：
- 基于高度: 50%
- 基于宽度: 30%  
- 基于面积: 20%
```

### 4. 多帧融合
- **窗口大小**: 5帧
- **权重分配**: 指数衰减
- **融合方法**: 加权移动平均

### 5. 运动模型约束
- **最大速度**: 1.5 m/s
- **最大加速度**: 2.0 m/s²
- **物理约束**: 人体运动学限制

### 6. 动态云台补偿
- **补偿范围**: ±5度
- **调整步长**: 0.5度/次
- **触发条件**: 高度误差>20cm

## 算法创新点

### 1. 智能深度估计
```python
# 置信度评估
confidence = 1.0 / (1.0 + abs(aspect_ratio - 2.5))

# 自适应权重
if confidence > 0.8:
    use_bbox_method()
else:
    use_ray_intersection()
```

### 2. 异常值剔除
```python
# IQR方法
q1, q3 = percentile(depths, [25, 75])
iqr = q3 - q1
valid_range = [q1 - 1.5*iqr, q3 + 1.5*iqr]
```

### 3. 平滑控制策略
```python
# 速度平滑
smoothing_factor = 0.7
new_vel = smooth * old_vel + (1-smooth) * target_vel

# 加速度限制
max_delta = 0.1 m/s per cycle
```

## 已知限制

1. **计算负载**: 增加约20% CPU使用率
2. **内存占用**: 增加约50MB（历史缓存）
3. **初始化时间**: 需要1-2秒收集初始数据
4. **环境依赖**: 光照变化可能影响检测框大小

## 优化建议

### 进一步改进方向
1. **GPU加速**: 将矩阵运算移至GPU
2. **深度学习**: 使用神经网络预测深度
3. **多传感器融合**: 加入IMU、激光雷达
4. **SLAM集成**: 使用视觉SLAM提高定位

### 参数调优建议
- 室内环境：减小运动模型的速度限制
- 室外环境：增大深度估计的范围
- 多目标场景：减小融合窗口大小
- 快速运动：增加卡尔曼过程噪声
