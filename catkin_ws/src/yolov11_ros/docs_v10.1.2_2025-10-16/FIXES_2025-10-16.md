# 2025-10-16 问题修复总结

## 修复的三个问题

### ✅ 问题1：无人机0追踪方向反向

**症状**：
- 航点飞行：两架无人机都正常 ✅
- 追踪模式：无人机1正常，无人机0前后反向 ❌

**根本原因**：
- 位置控制（航点）：直接指定目标坐标，不受坐标系影响
- 速度控制（追踪）：依赖机体坐标系，受初始偏航角影响
- 无人机0和1的初始偏航角可能相差180度

**解决方案（参数化配置）**：
```python
# drone_controller.py - 添加速度修正参数
self.velocity_invert_x = rospy.get_param('~velocity_invert_x', False)
self.velocity_invert_y = rospy.get_param('~velocity_invert_y', False)
self.yaw_rate_invert = rospy.get_param('~yaw_rate_invert', False)

# 应用修正
cmd.linear.x = -msg.linear.x if self.velocity_invert_x else msg.linear.x
cmd.linear.y = -msg.linear.y if self.velocity_invert_y else msg.linear.y
cmd.angular.z = -msg.angular.z if self.yaw_rate_invert else msg.angular.z
```

**配置（launch文件）**：
```xml
<!-- 无人机0 -->
<param name="velocity_invert_x" value="true" />
<param name="velocity_invert_y" value="true" />
<param name="yaw_rate_invert" value="true" />

<!-- 无人机1 -->
<param name="velocity_invert_x" value="false" />
<param name="velocity_invert_y" value="false" />
<param name="yaw_rate_invert" value="false" />
```

### ✅ 问题2：追踪效果差（人体无法保持居中）

**症状**：
- 追踪不稳定，目标偏离图像中心
- 复杂算法难以理解和调试

**根本原因**：
- 旧算法过于复杂，基于多个假设（45度云台等）
- 公式难以理解，增益难以调节

**解决方案（简化视觉伺服）**：
```python
# 新算法 - 简单直观
def _compute_tracking_velocity(self, target):
    # 1. 横向偏移 → 偏航控制（让无人机转向目标）
    u_offset = u_center - image_cx
    yaw_rate = -Kp_yaw * u_offset
    
    # 2. 横向偏移 → 横向速度（辅助快速对准）
    lateral_speed = -Kp_lateral * u_offset
    
    # 3. 目标大小 → 前后速度（保持理想距离）
    size_error = (ideal_box_size - box_size) / ideal_box_size
    forward_speed = Kp_distance * size_error
    
    # 4. 高度 → 保持3米
    height_error = ideal_distance - current_z
    z_speed = Kp_z * height_error
```

**控制增益**：
- `Kp_yaw = 0.003` - 偏航控制
- `Kp_lateral = 0.002` - 横向速度
- `Kp_distance = 1.5` - 前后距离
- `Kp_z = 0.5` - 高度保持

**优势**：
- 简单直观，易于理解
- 每个控制通道独立，易于调节
- 响应更快，追踪更稳定

### ✅ 问题3：坐标误差大（>2米）

**症状**：
- ActorInfo发布的坐标误差至少2米
- 记分系统无法消除目标（要求<1米）

**根本原因**：
1. 相机中心点参数不够精确
2. 坐标计算噪声大
3. 缺少平滑处理

**解决方案**：

#### 1. 修正相机参数
```python
# 旧参数
self.cx = 320.5  # ❌ 不够精确
self.cy = 180.5  # ❌ 不够精确

# 新参数
self.cx = 320.0  # ✅ 精确值（640/2）
self.cy = 180.0  # ✅ 精确值（360/2）
```

#### 2. 添加坐标平滑
```python
# 保留5帧历史
self.coord_history_x = []
self.coord_history_y = []

# 移动平均平滑
actor_x_smoothed = sum(coord_history_x) / len(coord_history_x)
actor_y_smoothed = sum(coord_history_y) / len(coord_history_y)
```

#### 3. 详细调试日志
```python
rospy.loginfo_throttle(1.0,
    f"[坐标-{color}] 原始:({x:.2f},{y:.2f}) "
    f"平滑:({x_smooth:.2f},{y_smooth:.2f}) | "
    f"无人机:({dx:.2f},{dy:.2f},{dz:.2f}) | "
    f"距离:{t:.2f}m")
```

**预期效果**：
- 减少坐标抖动
- 提高稳定性
- 误差降低到1米以内
