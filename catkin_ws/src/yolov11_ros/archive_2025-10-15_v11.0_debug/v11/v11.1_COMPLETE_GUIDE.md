## 核心修复

### 1. 使用正确的MAVROS接口（参考v9.2）

**PositionTarget + setpoint_raw/local**
- ✅ 明确的NED坐标系
- ✅ PX4原生支持
- ✅ 稳定可靠

### 2. 正确的坐标系转换

```python
# FLU(ROS) → NED(PX4)
target.velocity.x = cmd.linear.x      # X前不变
target.velocity.y = -cmd.linear.y     # Y左→右（反转）
target.velocity.z = -cmd.linear.z     # Z上→下（反转）
target.yaw_rate = -cmd.angular.z      # 偏航率反转
```

## 如果起飞卡住

### 检查1：高度是否更新
```bash
rostopic echo /typhoon_h480_0/mavros/local_position/pose
# 检查position.z是否在增加
```

### 检查2：是否在发送速度命令
```bash
rostopic hz /typhoon_h480_0/mavros/setpoint_raw/local
# 应该显示约20Hz
```

### 检查3：MAVROS状态
```bash
rostopic echo /typhoon_h480_0/mavros/state
# 确认：connected: True, mode: "OFFBOARD", armed: True
```

## 如果方向还是错误

### 检查航点加载
看日志中的">>> 确认"消息，确保加载了正确的航点文件。

### 检查速度命令
```bash
rostopic echo /drone_0/waypoint/cmd_vel
# 看linear.x, linear.y的值和符号
```

### 手动调整符号
如果方向完全相反，在`_compute_velocity()`中调整：
```python
# 尝试反转X
cmd_vel.linear.x = -forward_speed * math.cos(yaw_error)
```
