# v11.0 vs v11.1 对比

## 核心差异

### 设计理念

**v11.0（复杂模块化）**
- 目标：完整的模块化架构，支持1-6架无人机
- 结果：过度设计，双机场景下过于复杂

**v11.1（简化实用）**
- 目标：简洁稳定，专注双机场景
- 方法：参考v10.1.2成熟实现

## 控制流对比

### v11.0（复杂融合）
```
航点速度 ──┐
           ├──> 复杂融合 ──> MAVROS
追踪速度 ──┤   (权重、优先级、
           │    安全检查...)
避障速度 ──┘
```

### v11.1（简单选择）
```
航点速度 ──┐
           ├──> IF模式==WAYPOINT: 用航点
追踪速度 ──┘    ELSE: 用追踪 ──> MAVROS
```

## 问题解决对比

| 问题 | v11.0解决方案 | v11.1解决方案 |
|------|--------------|--------------|
| 解锁失败 | 复杂重试+状态检查 | 参考v10.1.2流程 |
| 速度为0 | 修复时序+分配逻辑 | 简单模式选择 |
| 方向反向 | 多次参数调整 | 直接用v10.1.2算法 |
| 航点混乱 | 多次文件交换 | 重新设计+自动加载 |
| 倒着飞 | 复杂的航点设计 | 简单合理的航点 |

## 启动命令

### v11.0
```bash
roslaunch yolov11_ros multi_drone_system.launch
# 使用复杂的模块化架构
```

### v11.1
```bash
roslaunch yolov11_ros simple_dual_drone_system.launch
# 使用简化的清晰架构
```

## 选择建议

### 使用v11.1（简化版）如果：
- ✅ 只需要双机场景
- ✅ 追求稳定可靠
- ✅ 需要快速调试
- ✅ 代码可读性优先

### 使用v11.0（复杂版）如果：
- ✅ 需要3-6架无人机
- ✅ 需要避障功能
- ✅ 需要复杂的目标分配
- ✅ 愿意花时间调试

## 迁移建议

### 从v11.0迁移到v11.1
1. 停止使用原launch文件
2. 使用simple_dual_drone_system.launch
3. 无需其他配置

### 后续升级
v11.1稳定后，可以逐步添加：
1. 多机目标分配（从v11.0移植）
2. 避障功能（从v11.0移植）
3. 更多安全检查
