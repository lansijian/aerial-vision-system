# 极简追踪控制 - 2025-10-16

## 核心理念

**让YOLO检测框保持在图像中心** - 这就是全部！

## 控制原理

### 简单比例控制

```python
# 1. 计算目标在图像中的位置
u = (bbox.xmin + bbox.xmax) / 2.0  # 水平中心
v = (bbox.ymin + bbox.ymax) / 2.0  # 垂直中心

# 2. 计算偏移（相对于图像中心320x180）
error_x = u - 320  # 水平偏移
error_y = v - 180  # 垂直偏移

# 3. 简单比例控制
linear.y = -error_x * 0.003  # 水平：右偏→左飞
linear.x = error_y * 0.005   # 垂直：下偏→前飞
linear.z = (3.0 - height) * 0.6  # 高度：保持3米
angular.z = -error_x * 0.002  # 偏航：保持中心
```

### 为什么这样简单有效？

1. **直接反馈**：检测框偏移直接转换为速度
2. **自然稳定**：目标越偏越快，越近越慢
3. **无需复杂计算**：不需要坐标变换、旋转矩阵
4. **鲁棒性好**：不受标定误差影响

## 控制增益

| 控制轴 | 增益 | 说明 |
|--------|------|------|
| X（前后） | 0.005 | 垂直偏移→前后速度 |
| Y（左右） | 0.003 | 水平偏移→左右速度 |
| Z（高度） | 0.6 | 高度误差→上下速度 |
| Yaw（偏航） | 0.002 | 水平偏移→偏航速度 |

## 平滑处理

```python
# 指数加权平均
alpha = 0.3  # 30%新值 + 70%旧值

cmd_vel.x = 0.3 * new_vel.x + 0.7 * last_vel.x
cmd_vel.y = 0.3 * new_vel.y + 0.7 * last_vel.y
cmd_vel.z = 0.3 * new_vel.z + 0.7 * last_vel.z
cmd_vel.yaw = 0.3 * new_yaw + 0.7 * last_yaw
```

## 目标丢失处理

```python
# 丢失超时：1.5秒
if lost_time > 1.5:
    # 请求返回航点
    request_waypoint_mode()
```

## 完整逻辑

```
检测到目标：
  1. 计算检测框中心
  2. 计算相对图像中心的偏移
  3. 比例控制计算速度
  4. 平滑处理
  5. 发布速度

目标丢失：
  1. 继续发布上次速度（衰减）
  2. 超过1.5秒→返回航点
```

## 参数调优

### 如果响应太慢
```python
linear.y = -error_x * 0.005  # 增大增益
linear.x = error_y * 0.008   # 增大增益
```

### 如果还是抖动
```python
alpha = 0.2  # 降低到20%新值，更平滑
```

### 如果高度不稳定
```python
height_error = 3.0 - current_height
if abs(height_error) > 0.3:  # 减小死区
    cmd_vel.linear.z = height_error * 0.8  # 增大增益
```
