# v11.1 最终架构 - 混合模式

**日期**：2025-01-15  
**版本**：v11.1  
**状态**：最终稳定版

## 核心改进

### 航点控制：直接发布（参考v9.2）

**waypoint_mission.py**:
- 计算航点导航速度
- **直接发布PositionTarget到MAVROS**
- 不再通过mission_controller转发
- 使用FRAME_BODY_NED坐标系

**优势**：
- ✅ 消除了转发的延迟
- ✅ 避免了坐标系转换错误
- ✅ 完全参考v9.2验证过的方式
- ✅ 不会出现"倒着飞"的问题

### 追踪控制：通过controller（保留v10.0.1）

**target_tracker.py**:
- 使用v10.0.1的追踪算法
- 发布Twist到mission_controller
- Controller转换FLU→NED后发布到MAVROS

**优势**：
- ✅ 使用验证过的v10.0.1算法
- ✅ 保留避障冲量叠加功能

## 关键修改

### 1. waypoint_mission.py

```python
# 添加导入
from mavros_msgs.msg import PositionTarget

# 修改发布器
self.setpoint_pub = rospy.Publisher(
    f'/{vehicle_type}_{drone_id}/mavros/setpoint_raw/local',
    PositionTarget, queue_size=1
)

# 修改计算函数（返回PositionTarget）
def _compute_waypoint_command(self):
    cmd = PositionTarget()
    cmd.coordinate_frame = PositionTarget.FRAME_BODY_NED
    cmd.type_mask = IGNORE位置和加速度
    
    # 计算速度（机体NED坐标系）
    cmd.velocity.x = vx
    cmd.velocity.y = vy
    cmd.velocity.z = vz
    cmd.yaw_rate = yaw_rate
    
    return cmd

# 直接发布
self.setpoint_pub.publish(cmd)
```

### 2. mission_controller.py

```python
# 不再订阅waypoint速度
# rospy.Subscriber('/waypoint_mission/cmd_vel', ...)

# 速度融合简化
def _fuse_velocities(self):
    if self.flight_mode == FlightMode.TRACKING:
        # 只处理追踪模式
        fused = self.tracking_vel
    else:
        # 航点模式由waypoint_mission直接控制
        fused = Twist()  # 空命令保持连接
```

### 3. target_tracker.py

保持v10.0.1的追踪算法：
- Kp_xy = 0.5
- Kp_yaw = 0.002  
- 基于图像的视觉伺服控制

## 话题结构

### WAYPOINT模式
```

  ↓ (PositionTarget, FRAME_BODY_NED)
/typhoon_h480_X/mavros/setpoint_raw/local
```

### TRACKING模式
```
target_tracker.py
  ↓ (Twist, FLU坐标系)
/drone_X/target_tracker/cmd_vel
  ↓
mission_controller.py
  ↓ (转换FLU→NED)
  ↓ (PositionTarget, FRAME_BODY_NED)
/typhoon_h480_X/mavros/setpoint_raw/local
```
