# v11.1 最终修复 - 2025-10-16

## 核心问题与解决方案

### 问题1：追踪飞太高 ✅ 已解决

**根本原因**：
- 之前使用 `cmd_vel.linear.z = kp_z * (ideal_distance - height)` 
- 这会根据目标视觉大小动态调整高度
- 导致高度不稳定，越飞越高

**v11.1解决方案（复刻v9.2）**：
```python
# 高度保持（不是高度控制）
height_error = target_height - current_height

if abs(height_error) < tolerance:
    cmd_vel.linear.z = 0.0  # 误差小，不调整
else:
    cmd_vel.linear.z = height_kp * height_error  # 误差大，回到目标高度
    cmd_vel.linear.z = clip(cmd_vel.linear.z, -0.8, 0.8)
```

**关键**：target_height是**固定值**（3米），不是根据视觉计算的。

### 问题2：剧烈抖动 ✅ 已解决

**根本原因**：
- 像素级的小抖动直接转换为速度
- 无平滑处理
- 响应过快

**v11.1解决方案（参考plan3）**：
```python
# 速度平滑（指数加权平均）
alpha = 0.3  # 30%新值 + 70%旧值

cmd_vel.x = alpha * new_vel.x + (1 - alpha) * last_vel.x
cmd_vel.y = alpha * new_vel.y + (1 - alpha) * last_vel.y
cmd_vel.z = alpha * new_vel.z + (1 - alpha) * last_vel.z
cmd_vel.yaw = alpha * new_yaw + (1 - alpha) * last_yaw
```

### 问题3：左右方向问题 ✅ 已解决

**v11.1方案（完全复刻v9.2/XTDrone）**：
```python
# 使用XTDrone的几何变换公式
u_velocity = -kp_xy * u_
v_velocity = -kp_xy * v_

# XTDrone标准公式（不加额外的负号）
x_velocity = v_velocity * z_depth / denom
y_velocity = (z_depth * u_velocity - u_ * cos(theta) * x_velocity) / fx

cmd_vel.linear.x = x_velocity
cmd_vel.linear.y = y_velocity
```

## v11.1最终架构

### 追踪控制（完全复刻v9.2）
```
1. 像素偏移 → 像素速度（u_velocity, v_velocity）
2. XTDrone几何变换 → 世界速度（x_velocity, y_velocity）
3. 高度保持 → z_velocity（保持固定高度）
4. 偏航控制 → yaw_rate
5. 速度平滑 → 最终速度（plan3算法）
```
