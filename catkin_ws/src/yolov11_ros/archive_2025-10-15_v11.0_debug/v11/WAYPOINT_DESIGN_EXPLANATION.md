# 双机航点设计说明

## Spawn配置（robocup.launch）

| 无人机 | X | Y | Z | Yaw(Y) | 朝向 | 说明 |
|--------|---|---|---|--------|------|------|
| typhoon_h480_0 | 0 | -3 | 1 | 0° | 北 | 左侧位置 |
| typhoon_h480_1 | 3 | -3 | 1 | 0° | 北 | 右侧位置 |

## 航点设计原则

### 1. 起点选择
两台无人机的第一个航点应该：
- **drone_0**: (0, 0) - 从(0,-3)向北3米，不需要转向 ✅
- **drone_1**: (3, 0) - 从(3,-3)向北3米，不需要转向 ✅

### 2. 巡检路线
- **drone_0**: 覆盖西半区域（X < 50）
- **drone_1**: 覆盖东半区域（X > 50）

### 3. 飞行方向
两台无人机都保持自然的飞行姿态（云台朝前），不需要转180度

## 当前航点配置

### drone_0航点序列
```
起点: (0, -3) → Yaw=0° (朝北)
1. (0, 0) - 向北3米 ✅
2. (-15, 0) - 向西15米
3. (-15, 45) - 向北45米
4. (45, 45) - 向东60米
5. ... 继续西半区巡检
```

### drone_1航点序列  
```
起点: (3, -3) → Yaw=0° (朝北)
1. (3, 0) - 向北3米 ✅
2. (105, 0) - 向东102米
3. (105, 45) - 向北45米
4. (45, 45) - 向西60米
5. ... 继续东半区巡检
```

## 预期飞行行为

### drone_0
- 起飞到(0, -3, 3)
- 向前飞到(0, 0, 3) - 云台朝北
- 向左飞到(-15, 0, 3) - 云台朝西
- 继续巡检西半区

### drone_1
- 起飞到(3, -3, 3)
- 向前飞到(3, 0, 3) - 云台朝北
- 向右飞到(105, 0, 3) - 云台朝东
- 继续巡检东半区

## 优势

1. ✅ 两台无人机都不需要转180度
2. ✅ 云台始终朝向飞行方向
3. ✅ 覆盖不同的区域，避免重复
4. ✅ 高效的双机协同搜索
