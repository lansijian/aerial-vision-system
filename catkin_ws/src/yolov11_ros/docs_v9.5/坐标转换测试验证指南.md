## 常见问题排查

### 1. 误差仍然很大（>5米）

**检查项：**
- 确认coordinate_offset_y设置正确（通常为-3.0）
- 检查四元数是否正常（w应该接近1或-1）
- 确认相机参数正确（cy应为180.5，不是240）

### 2. 射线向上警告

**症状：**
```
[警告] 射线向上! UAV_z=3.00, target_z=0.90, ray_z=0.123
```

**解决：**
- 检查云台角度是否正确（应为负值，如-45度）
- 确认无人机姿态正常

### 3. 无检测结果

**检查：**
```bash
# 查看YOLO是否正常工作
rostopic echo /yolo_detector/drone_0/detections

# 检查相机图像
rosrun image_view image_view image:=/typhoon_h480_0/cgo3_camera/image_raw
```
