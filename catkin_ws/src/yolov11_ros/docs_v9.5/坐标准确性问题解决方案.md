# 坐标准确性问题解决方案 - v9.5.7

## 问题诊断

### 1. 发现的问题

通过debug工具分析，发现以下关键问题：

1. **坐标系理解**
   - MAVROS local_position：相对于无人机起飞点的位置（EKF2本地坐标系）
   - Gazebo model_state：Gazebo世界坐标系中的绝对位置
   - 重要：robocup.launch中的位置(如y=-3)是无人机的起飞位置
   - 因此：世界坐标 = local_position + 起飞位置偏移

2. **四元数符号问题**
   - MAVROS四元数的w分量可能为负值（例如：w=-1.000）
   - 需要确保四元数归一化和符号一致性
   - 这可能导致旋转矩阵计算错误

3. **相机参数错误**
   - 原代码中cy=240是错误的，实际应为180.5（图像高度360的一半）
   - 这会导致射线方向计算错误

4. **云台旋转不完整**
   - 原代码只考虑了pitch角度
   - 未考虑yaw和roll的影响

## 解决方案

### 1. 修正相机参数

```python
# 修正后的相机参数（校准值）
self.fx = 205.47  # 焦距
self.fy = 205.47
self.cx = 320.5  # 光心x（精确值）
self.cy = 180.5  # 光心y（360/2的精确值）
self.image_width = 640
self.image_height = 360  # 实际高度
```

### 2. 处理四元数符号问题

```python
# 处理四元数符号问题（确保w为正）
if w < 0:
    w, x, y, z = -w, -x, -y, -z

# 归一化四元数（防止数值误差）
norm = math.sqrt(w*w + x*x + y*y + z*z)
if norm > 0:
    w, x, y, z = w/norm, x/norm, y/norm, z/norm
```

### 3. 完整的云台旋转矩阵

```python
# Pitch绕Body Y轴旋转（俯仰，负值向下）
R_pitch = np.array([
    [math.cos(pitch_rad), 0, math.sin(pitch_rad)],
    [0, 1, 0],
    [-math.sin(pitch_rad), 0, math.cos(pitch_rad)]
])

# Yaw绕Body Z轴旋转（偏航）
R_yaw = np.array([
    [math.cos(yaw_rad), -math.sin(yaw_rad), 0],
    [math.sin(yaw_rad), math.cos(yaw_rad), 0],
    [0, 0, 1]
])

# Roll绕Body X轴旋转（滚转）
R_roll = np.array([
    [1, 0, 0],
    [0, math.cos(roll_rad), -math.sin(roll_rad)],
    [0, math.sin(roll_rad), math.cos(roll_rad)]
])

# 应用云台旋转
R_gimbal = R_yaw @ R_pitch @ R_roll
```

### 4. 坐标系偏移补偿（必需）

```python
# 坐标系偏移参数：设置为无人机的起飞位置
self.coordinate_offset_x = rospy.get_param('~coordinate_offset_x', 0.0)
self.coordinate_offset_y = rospy.get_param('~coordinate_offset_y', 0.0)
self.coordinate_offset_z = rospy.get_param('~coordinate_offset_z', 0.0)

# 获取无人机当前位置（相对于起飞点）
drone_x = self.current_pose.position.x
drone_y = self.current_pose.position.y
drone_z = self.current_pose.position.z

# 应用偏移得到世界坐标
if self.coordinate_offset_x != 0.0 or self.coordinate_offset_y != 0.0 or self.coordinate_offset_z != 0.0:
    drone_x += self.coordinate_offset_x
    drone_y += self.coordinate_offset_y
    drone_z += self.coordinate_offset_z
```

**重要说明**：
- MAVROS local_position是相对于起飞点的位置
- 必须加上起飞位置偏移才能得到世界坐标
- 例如：无人机0从(0,-3,1)起飞，需设置offset_y=-3, offset_z=1
- 例如：无人机1从(3,-3,1)起飞，需设置offset_x=3, offset_y=-3, offset_z=1

## 使用方法

### 1. 基本使用

```bash
rosrun yolov11_ros human_tracker.py _drone_id:=0
```

### 2. 使用multi_drone_system.launch配置参数

在`multi_drone_system.launch`中，human_tracker已经配置了必要的参数：

```xml
<!-- 人体追踪器 -->
<node pkg="yolov11_ros" type="human_tracker.py" name="human_tracker" output="screen">
    <param name="drone_id" value="0" />
    <param name="vehicle_type" value="$(arg vehicle_type)" />
    <param name="detection_topic" value="/yolo_detector/drone_0/detections" />
    <param name="ideal_tracking_distance" value="3.0" />
    <param name="max_tracking_speed" value="2.0" />
    
    <!-- 坐标系偏移参数：无人机0起飞位置(0,-3,1) -->
    <param name="coordinate_offset_x" value="0.0" />
    <param name="coordinate_offset_y" value="-3.0" />
    <param name="coordinate_offset_z" value="1.0" />
    
    <!-- 目标高度参数 -->
    <param name="target_height" value="0.9" />
    <param name="assumed_human_height" value="1.7" />
</node>
```

对于无人机1：
```xml
<!-- 坐标系偏移参数：无人机1起飞位置(3,-3,1) -->
<param name="coordinate_offset_x" value="3.0" />
<param name="coordinate_offset_y" value="-3.0" />
<param name="coordinate_offset_z" value="1.0" />
```

- 位置误差从15米以上降低到1米以内

## 注意事项

1. **坐标系偏移值需要根据实际环境调整**
   - 可以通过debug_coordinate_system.py获取准确的偏移值
   - 不同的起飞位置可能需要不同的偏移值

2. **相机参数必须准确**
   - 使用校准后的参数
   - 确认图像实际分辨率

3. **云台角度**
   - 默认使用-45度俯仰角
   - 如果有实际云台反馈，应该订阅真实角度
