## 六区域划分方案对比

### 方案A：水平三分法（组员方案）
```
左下(-45,50,-48.7,-20) | 右下(45,120,-48.7,-20)
左中(-45,50,-25,25)     | 右中(45,120,-25,25)
左上(-45,50,20,49.2)    | 右上(45,120,20,49.2)
```

**优点**：
- 左右对称，清晰
- 覆盖所有区域

**缺点**：
- 初始位置都在左侧，右侧3台需飞行很远
- 未考虑中间可变道路

### 方案B：均匀六分法
```
左(-45,7.5) | 中左(7.5,70) | 右(70,120)
×
下(-48.7,-15) | 上(-15,49.2)
```

**优点**：
- 更均匀覆盖
- 考虑了中间道路（大都在7.5-70区间）

**缺点**：
- 中间区域过大(7.5-70)
- 分界点未优化

## 障碍物分析

从`robocup.world`分析：
- **房屋(house)**: 主要在道路两侧
- **加油站(gas_station)**: (61.88, -30.82)
- **路灯(lamp_post)**: 沿道路分布
- **垃圾箱(dumpster)**: (15.94, -13.63)
- **停车标志(stop_sign)**: 路口附近

**关键发现：障碍物主要在道路两侧，飞行高度5.5m可避开大部分障碍物**

## 初步结论

1. **中间道路高度可变**(x=30-75)，需要设计能覆盖全范围的方案
2. **初始位置集中在左侧**，需优化飞行距离
3. **飞行高度5.5m**可避开大部分障碍物
4. **路口是关键搜索点**（9个路口）
