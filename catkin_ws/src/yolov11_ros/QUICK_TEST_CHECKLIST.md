## 🐛 如果测试失败

### 现象1: 框在左边，无人机向右转 ❌

**日志特征**:
```
[调试-偏航] u_offset=-50.0px | yaw=+0.100rad/s
```

**原因**: 符号修复未生效

**检查**:
```bash
# 查看human_tracker.py第299行
grep "yaw_rate_raw = " catkin_ws/src/yolov11_ros/scripts/human_tracker.py

# 应该看到（无负号）：
# yaw_rate_raw = self.Kp_yaw * u_offset
```

---

### 现象2: 框抖动严重 ❌

**日志特征**:
```
[调试-平滑] 原始: u=320.1 h=119.7 | 平滑后: u=285.6 h=98.3
```
平滑后仍然跳动很大

**解决**:
```bash
rosparam set /drone_0/human_tracker/bbox_smooth_frames 5
rosparam set /drone_0/human_tracker/dead_zone_px 15
```

---

### 现象3: 追踪响应太慢 ❌

**日志特征**:
```
[调试-偏航] u_offset=-100.0px | yaw=-0.200rad/s
```
偏移很大但yaw很小

**解决**:
```bash
rosparam set /drone_0/human_tracker/Kp_yaw 0.003
rosparam set /drone_0/human_tracker/Kp_distance 2.0
```
