## 重要提醒

### ⚠️ 颜色映射问题
**关键发现**：YOLO训练数据的颜色标签必须与官方标准一致！

**官方标准**（固定，不可修改）：
```python
actor_id_dict = {
    'green': [0],    # actor_0
    'blue': [1],     # actor_1
    'brown': [2],    # actor_2
    'white': [3],    # actor_3
    'red': [4, 5]    # actor_4, actor_5
}
```

**解决方案**：
1. 确保robocup.world中的actor颜色与YOLO标签一致
2. 或重新训练YOLO，使用官方标准颜色标签

详见：`v10.0_颜色映射解决方案.md`
