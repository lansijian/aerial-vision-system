# 坐标系偏移补偿修复说明

**日期**: 2025-10-14  
**问题**: 0号无人机识别时y轴存在固定偏差  
**原因**: 无人机spawn位置不在原点，导致MAVROS坐标系与Gazebo世界坐标系偏移

---

## 问题根源

从 `robocup.launch` 发现：
```xml
<!-- 0号无人机 -->
<arg name="x" value="0"/>
<arg name="y" value="-3"/>  ← y轴偏移-3米！
<arg name="z" value="1"/>

<!-- 1号无人机 -->
<arg name="x" value="3"/>    ← x轴偏移3米！
<arg name="y" value="-3"/>   ← y轴偏移-3米！
<arg name="z" value="1"/>
```

**坐标系关系**：
- **MAVROS local_position**：相对于起飞点(spawn点)的ENU坐标
- **Gazebo世界坐标**：绝对世界坐标
- **记分系统**：使用Gazebo世界坐标进行误差计算

**转换公式**：
```
gazebo_x = mavros_x + spawn_offset_x
gazebo_y = mavros_y + spawn_offset_y
```

---

## 修复内容

### 1. human_tracker.py 修改

添加偏移补偿参数：
```python
# 坐标系偏移补偿（MAVROS→Gazebo世界坐标）
self.spawn_offset_x = rospy.get_param('~spawn_offset_x', 0.0)
self.spawn_offset_y = rospy.get_param('~spawn_offset_y', 0.0)
```

坐标计算时补偿偏移：
```python
# 计算目标位置（MAVROS坐标系）
actor_x_local = drone_x + t * ray_enu[0]
actor_y_local = drone_y + t * ray_enu[1]

# 转换到Gazebo世界坐标系（补偿起飞点偏移）
actor_x = actor_x_local + self.spawn_offset_x
actor_y = actor_y_local + self.spawn_offset_y
```

### 2. multi_drone_system.launch 修改

为每架无人机配置对应的偏移量：

**0号无人机** (spawn位置: 0, -3, 1):
```xml
<param name="spawn_offset_x" value="0.0" />
<param name="spawn_offset_y" value="-3.0" />
```

**1号无人机** (spawn位置: 3, -3, 1):
```xml
<param name="spawn_offset_x" value="3.0" />
<param name="spawn_offset_y" value="-3.0" />
```

**2-5号无人机** (待确定spawn位置):
```xml
<param name="spawn_offset_x" value="0.0" />
<param name="spawn_offset_y" value="0.0" />
```

## 注意事项

1. **如果增加更多无人机**，必须在 `robocup.launch` 中确认spawn位置，然后在 `multi_drone_system.launch` 中设置对应的偏移量

2. **偏移量必须准确**，否则误差会增大而不是减小

3. **验证方法**：
   ```bash
   # 查看actor真实位置
   rostopic echo /gazebo/model_states
   
   # 查看检测位置
   rostopic echo /actor_red1_info
   
   # 计算误差
   误差 = sqrt((真实x - 检测x)^2 + (真实y - 检测y)^2)
   ```
