# v10.0 升级说明 - 完全重构版

## 版本信息

- **版本号**: v10.0.0
- **发布日期**: 2025-10-13
- **重构类型**: 完全重构（记分系统 + 坐标计算）

## 核心更新

### ✅ 1. 记分系统完全重构

**参考官方`score_cal.py`，100%遵循官方逻辑：**

- 误差阈值：1.0米（官方标准）
- 持续检测：15秒确认（官方标准）
- 得分公式：完全按照官方公式
- 传感器成本：单目相机(500) + 云台(200) = 700

### ✅ 2. 坐标计算最优算法

**高精度定位，确保1米误差阈值：**

- 完整坐标变换链（像素→相机→Body→ENU）
- 精确相机参数（fx=205.47, cy=180.5）
- 完整姿态补偿（四元数归一化）
- 三轴云台角度支持
- 射线-地面交点法

### ✅ 3. 动态扩展支持（重要！）

**完全无硬编码，支持2-6架无人机动态切换：**

```bash
# 2架无人机（默认）
roslaunch yolov11_ros multi_drone_system.launch

# 6架无人机
roslaunch yolov11_ros multi_drone_system.launch num_drones:=6

# 3架无人机
roslaunch yolov11_ros multi_drone_system.launch num_drones:=3
```

## 常见问题

### Q1: 如何验证支持6机？

A: 检查launch文件中的条件判断：
```bash
grep "num_drones" launch/multi_drone_system.launch
# 应该看到 if="$(eval arg('num_drones') >= N)" 的条件判断
```

### Q2: 坐标还是不准怎么办？

A: 
1. 确认云台角度正确（默认-45度）
2. 检查MAVROS local_position是否正常
3. 查看human_tracker日志中的射线方向

### Q3: 记分系统不工作？

A: 
1. 确认话题名称：`/actor_blue_info`（不是`/actor_blue`）
2. 确认ActorInfo消息格式：`(x, y, cls)`
3. 检查误差是否<1米

### Q4: 如何添加第7架无人机？

A: v10.0设计最多支持6架（与官方一致）。如需更多，需修改：
1. launch文件添加drone_6配置
2. 更新记分系统（官方最多6个actor）
3. 添加对应的航点文件
