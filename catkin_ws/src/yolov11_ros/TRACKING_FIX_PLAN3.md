# 追踪控制修复文档 - 参考plan3优化版

## 🔍 问题诊断

### 问题1：**偏航增益过大（100倍错误）**

**症状：**
- 左右控制剧烈抖动
- 无法稳定保持检测框在图像中心
- 无人机左右摇摆，目标在视野中晃动

**根本原因：**

对比分析显示，偏航增益参数错误：

| 版本 | 增益计算方式 | 实际增益范围 | 问题 |
|------|-------------|-------------|------|
| **plan3_optimized（正确）** | 固定分级增益 | 0.0012 - 0.006 | ✅ 稳定 |
| **v10.1.2-simplified（错误）** | `100.0 / box_height` | ~0.625 | ❌ 过大100倍 |

**详细对比：**

```python
# ✅ plan3_optimized（正确）
yaw_gains = {
    'very_close': 0.0012,   # |u| < 80px
    'close': 0.0025,        # 80 < |u| < 150px
    'medium': 0.0040,       # 150 < |u| < 220px
    'far': 0.0060           # |u| > 220px
}
yaw_rate = -u * yaw_gain
```

```python
# ❌ v10.1.2-simplified（错误）
Kp_yaw_base = 100.0
Kp_yaw = 100.0 / max(box_height, 20)  # box_height=160时 → 0.625
yaw_rate = -Kp_yaw * u_offset  # 增益0.625，比plan3大100倍！
```

**计算示例：**
- 当 `u_offset = 100px`，`box_height = 160px` 时：
  - plan3：`yaw_rate = -100 * 0.0025 = -0.25 rad/s` ✅ 平稳
  - 错误：`yaw_rate = -(100/160) * 100 = -62.5 rad/s → clip到-0.6` ❌ 剧烈

### 问题2：**距离度量不一致**

**症状：**
- 距离控制不稳定
- 前后速度抖动

**根本原因：**
- plan3使用 `box_size = width × height`（面积）
- 错误版本使用 `box_height`（单一维度）

面积更稳定，因为它综合了宽高两个维度的信息。

## ✅ 修复方案

### 1. **修复偏航控制**

#### 参数修改

```python
# ✅ 正确的分级增益（参考plan3）
self.yaw_gains = {
    'very_close': 0.0012,   # |u| < 80px   - 中心区域，微调
    'close': 0.0025,        # 80-150px     - 接近区域，适中
    'medium': 0.0040,       # 150-220px    - 中等偏移，加快
    'far': 0.0060           # >220px       - 边缘区域，急速
}
```

#### 控制逻辑

```python
# 分级选择增益
abs_u = abs(u_offset)
if abs_u < 80:
    yaw_gain = self.yaw_gains['very_close']
elif abs_u < 150:
    yaw_gain = self.yaw_gains['close']
elif abs_u < 220:
    yaw_gain = self.yaw_gains['medium']
else:
    yaw_gain = self.yaw_gains['far']

# 计算期望偏航率
desired_yaw_rate = -u_offset * yaw_gain

# 平滑滤波（alpha=0.30）
yaw_rate = 0.30 * desired_yaw_rate + 0.70 * last_yaw_rate
```

**优势：**
- 小偏移时微调，大偏移时加速
- 平滑滤波避免抖动
- 增益合理，响应稳定

### 2. **修复距离控制**

#### 使用box_size面积

```python
# ✅ 使用面积（参考plan3）
box_width = bbox.xmax - bbox.xmin
box_height = bbox.ymax - bbox.ymin
box_size = box_width * box_height  # 面积

# 理想值（3米距离）
ideal_box_size = 1067  # px²

# 误差计算
size_error = (ideal_box_size - box_size) / ideal_box_size
forward_speed = Kp_distance * size_error
```

**优势：**
- 面积综合宽高信息，更稳定
- 与plan3一致，经过验证

### 3. **其他优化**

#### 横向速度禁用

```python
# plan3中基本不使用横向速度，全靠偏航对齐
self.cmd_vel.linear.y = 0.0
```

**原因：**
- 偏航对齐更准确
- 避免横向漂移
- 简化控制逻辑

### 响应速度对比

| 偏移量 | plan3偏航率 | 错误偏航率 | 结果 |
|--------|------------|-----------|------|

- 导致左右剧烈摇摆

## 🎯 修复后的控制策略

### 整体控制流程

```
检测YOLO框 → 计算偏移(u_offset, box_size)
    ↓
┌─────────────────────────────────────┐
│ 1. 偏航控制（优先级最高）           │
│    - 分级增益：0.0012-0.006        │
│    - 平滑滤波：alpha=0.30          │
│    - 目标：保持u_offset ≈ 0        │
├─────────────────────────────────────┤
│ 2. 前后速度控制                     │
│    - 基于box_size面积              │
│    - 目标：box_size = 1067px²      │
│    - Kp_distance = 2.0             │
├─────────────────────────────────────┤
│ 3. 横向速度                         │
│    - 禁用（vy=0）                   │
│    - 完全依赖偏航对齐               │
├─────────────────────────────────────┤
│ 4. 高度保持                         │
│    - vz=0，交给PX4                 │
└─────────────────────────────────────┘
```

### 分级增益逻辑

```
偏移量(px)      增益        响应速度
   0-80    →  0.0012  →  微调（中心死区）
  80-150   →  0.0025  →  适中（稳定追踪）
 150-220   →  0.0040  →  加快（纠正偏离）
  >220     →  0.0060  →  急速（防止丢失）
```

## 🔧 参数配置

### 核心参数

```yaml
# 偏航控制（分级增益）
yaw_gain_very_close: 0.0012  # |u| < 80px
yaw_gain_close: 0.0025       # 80 < |u| < 150px
yaw_gain_medium: 0.0040      # 150 < |u| < 220px
yaw_gain_far: 0.0060         # |u| > 220px

# 平滑滤波
yaw_smooth_alpha: 0.30       # 30%新值 + 70%旧值

# 距离控制
ideal_box_size: 1067         # px² (3米距离)
Kp_distance: 2.0             # 距离控制增益

# 速度限制
max_vx: 3.0                  # 最大前后速度
max_vy: 0.5                  # 最大横向速度（基本不用）
max_yaw_rate: 0.5            # 最大偏航率
```

### 参数调优建议

**如果追踪太慢（转不过来）：**
```yaml
yaw_gain_medium: 0.0050      # 提高中等增益
yaw_gain_far: 0.0080         # 提高远距增益
```

**如果追踪抖动（不稳定）：**
```yaml
yaw_gain_very_close: 0.0010  # 降低中心增益
yaw_smooth_alpha: 0.20       # 增强平滑
```

**如果距离控制不佳：**
```yaml
Kp_distance: 2.5             # 提高距离增益
ideal_box_size: 1200         # 调整理想框大小
```

## ⚠️ 注意事项

1. **不要随意修改增益**
   - 0.0012-0.006是经过验证的值
   - 增益过大会导致抖动
   - 增益过小会响应迟钝

2. **平滑系数的影响**
   - alpha=0.30：30%响应新值
   - 过大会抖动，过小会迟钝
   - 建议范围：0.20-0.40

3. **box_size与距离的关系**
   - 2米：~2400 px²
   - 3米：~1067 px²
   - 4米：~600 px²
   - 5米：~384 px²

## 🎓 经验总结

### 关键教训
1. **增益参数必须准确校准**
   - 100倍的错误导致完全无法使用
   - 参考成熟方案而非主观臆断

2. **分级控制优于自适应**
   - plan3的固定分级增益更稳定
   - 自适应容易引入不确定性

3. **平滑滤波必不可少**
   - 传感器噪声会导致抖动
   - 30%新值+70%旧值是良好平衡

4. **简单即美**
   - 横向速度禁用反而更稳定
   - 专注偏航对齐是正确方向
