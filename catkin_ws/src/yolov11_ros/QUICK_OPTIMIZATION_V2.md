# 追踪优化v2 - 快速参考

## 🔍 问题（从终端数据发现）

```
[中心追踪] 偏移:(u=-307px, v=-34px)   ← ❌ 严重偏离
[中心追踪] 偏移:(u=+258px, v=-44px)   ← ❌ 严重偏离
yaw_rate = ±0.500 (频繁限幅)          ← ❌ 响应不足
UnboundLocalError: yaw_gain未定义     ← ❌ 代码错误
```

**核心问题：响应速度不够，无法保持目标在中心！**

---

## ✅ 解决方案

### 1. 修复代码错误
```python
# ❌ 错误（死区内yaw_gain未定义）
if abs_u < 10:
    yaw_rate = 0.0
else:
    yaw_gain = ...

# ✅ 正确（移除死区，始终计算）
if abs_u < 80:
    yaw_gain = 0.0020
elif abs_u < 150:
    yaw_gain = 0.0040
# ...
```

### 2. 提高偏航增益（33-67%）
| 分级 | 原值 | 新值 | 提升 |
|------|------|------|------|
| very_close | 0.0012 | **0.0020** | +67% |
| close | 0.0025 | **0.0040** | +60% |
| medium | 0.0040 | **0.0060** | +50% |
| far | 0.0060 | **0.0080** | +33% |

### 3. 提高最大偏航率
```python
max_yaw_rate: 0.5 → 0.8 rad/s (+60%)
```

### 4. 提高平滑系数
```python
yaw_smooth_alpha: 0.30 → 0.50 (+67%)
```
