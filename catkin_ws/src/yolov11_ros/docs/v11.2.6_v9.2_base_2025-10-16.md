# v11.2.6 采用v9.2架构 - 2025年10月16日

## 背景

经过多次尝试修复抖动问题后，决定直接采用经过验证的v9.2版本架构。

## 主要变更

### 1. 完全替换waypoint_mission.py
- 使用v9.2的waypoint_flight.py代码
- 保留了30Hz后台setpoint线程机制
- 简化了控制逻辑

### 2. 核心特性（来自v9.2）
```python
# 后台线程：30Hz持续发送setpoint
def _background_setpoint_sender(self):
    rate = rospy.Rate(30)
    while not rospy.is_shutdown():
        if not self.mission_active:
            # 发送位置保持
            publish_position_hold()
        rate.sleep()
```

### 3. 控制流程
1. **后台线程**：始终运行，保持OFFBOARD模式
2. **任务未激活**：后台线程发送位置保持
3. **任务激活**：主控制回调接管，发送速度命令
4. **模式切换**：通过flight_mode话题控制

### 4. 与mission_controller集成
- waypoint_mission不再管理起飞
- 由mission_controller统一控制任务流程
- 通过flight_mode话题切换模式

## 关键改进

1. **稳定性**：30Hz持续通信，避免OFFBOARD模式丢失
2. **平滑控制**：后台线程确保控制命令连续性
3. **简化架构**：去除复杂的状态管理

## 参数配置

- 所有无人机initial_delay = 1.0秒（同时起飞）
- waypoint_reached_threshold = 0.3米
- position_hold_time = 0.1秒
- cruise_speed = 5.0 m/s

## 预期效果

1. 解决抖动问题
2. 所有无人机同时起飞
3. 稳定执行航点任务
4. 平滑切换到追踪模式
