# v11.2.5 添加后台线程机制 - 2025年10月16日

## 问题分析

用户反馈v9.2版本可以正常起飞执行航点，没有抖动问题。通过对比v9.2代码发现关键差异：

### v9.2的核心机制
1. **30Hz后台线程**：持续发送setpoint保持OFFBOARD模式
2. **位置保持**：任务未激活时发送当前位置保持命令
3. **控制权移交**：任务激活后主循环接管控制

## 实现方案

### 1. 后台线程设计
```python
def _background_setpoint_sender(self):
    """30Hz持续发送setpoint保持OFFBOARD模式"""
    rate = rospy.Rate(30)
    while not rospy.is_shutdown() and self.background_setpoint_active:
        if not self.is_active and self.current_pose:
            # 发送位置保持命令
            cmd = PositionTarget()
            cmd.coordinate_frame = FRAME_LOCAL_NED
            cmd.type_mask = IGNORE_VX | IGNORE_VY | IGNORE_VZ | ...
            cmd.position = current_position
            cmd.yaw = current_yaw
            self.setpoint_pub.publish(cmd)
        rate.sleep()
```

### 2. 控制策略
- **任务未激活**：后台线程发送位置保持
- **任务激活**：主控制循环发送速度命令
- **无缝切换**：避免控制权冲突

### 3. 关键改进
1. **持续通信**：确保与PX4的通信不中断
2. **稳定悬停**：未执行任务时保持当前位置
3. **避免抖动**：消除控制命令的不连续性

## 技术细节

### 启动流程
1. 初始化时启动后台线程
2. 后台线程以30Hz频率运行
3. 主控制循环以20Hz频率运行

### 线程安全
- 使用`is_active`标志协调控制权
- 后台线程只在非活动状态发送命令
- 主循环只在活动状态发送命令

## 预期效果

1. **消除抖动**：持续稳定的控制命令流
2. **平滑过渡**：任务切换时无跳变
3. **可靠悬停**：非任务期间稳定保持位置
