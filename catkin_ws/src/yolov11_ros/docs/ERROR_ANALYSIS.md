# 误差分析报告 - v10.1问题诊断与v10.2解决方案

## 问题概述

v10.1版本引入先进算法后，误差反而从2米增加到5米以上，本文档分析问题原因并提供解决方案。

## v10.1误差分析

### 实测数据
| Actor | 真实坐标 | 检测坐标 | 误差距离 |
|-------|---------|---------|---------|
| BROWN | (-37.9, -5.2) | (-33.8, -1.7) | 5.41m |
| RED | (25.0, -15.0) | (22.7, -16.6) | 2.80m |
| WHITE | (5.0, 7.9) | 未检测到 | -- |

### 误差特征
1. **Y轴误差显著**：Y轴误差普遍大于X轴
2. **系统性偏移**：所有目标的Y值都偏大（更接近0）
3. **不稳定性**：误差波动范围大

## 问题根源分析

### 1. 卡尔曼滤波器问题
```python
# 问题代码
kf.predict()  # 可能引入延迟
kf.update(measurement)  # 初始化慢，需要时间收敛
```

**问题**：
- 滤波器需要时间收敛，初期误差大
- 预测模型不准确时会放大误差
- 参数调优困难，默认参数不适合

### 2. 自适应相机标定问题
```python
# 问题代码
self.fx *= (1 + lr * np.sign(error_x))  # 可能错误调整
```

**问题**：
- 学习率固定，可能过度调整
- 没有验证机制，可能越调越差
- 基于局部误差调整全局参数

### 3. 过度融合问题
```python
# 问题代码
# 多种方法加权，但权重可能不合理
depth = 0.5 * depth_height + 0.3 * depth_width + 0.2 * depth_area
```

**问题**：
- 权重固定，不同场景下最优权重不同
- 某个方法误差大时会污染整体结果
- 计算复杂度增加但精度未必提升

### 4. 坐标系转换问题

最关键的问题可能是坐标系转换和偏移补偿：

```python
# 可能的问题
actor_x = actor_x_local + spawn_offset_x  # spawn_offset可能不准确
actor_y = actor_y_local + spawn_offset_y  # 需要额外的系统校准
```

## v10.2解决方案

### 1. 回归简单可靠算法

**移除**：
- ❌ 卡尔曼滤波器
- ❌ 自适应相机标定
- ❌ 复杂的多层融合

**保留**：
- ✅ 简单移动平均（3-5帧）
- ✅ 中位数滤波（去除异常值）
- ✅ 基础的深度估算

### 2. 添加系统校准偏移

```python
# v10.2新增
self.calibration_offset_x = 0.0   # 通过实测调整
self.calibration_offset_y = -2.0  # 补偿Y轴系统误差

# 应用校准
actor_x = actor_x_local + spawn_offset_x + calibration_offset_x
actor_y = actor_y_local + spawn_offset_y + calibration_offset_y
```

### 3. 优化追踪控制

```python
# v10.2改进
# 1. 降低控制增益，提高稳定性
self.Kp_xy = 0.4  # (原0.6)

# 2. 添加死区，避免抖动
if abs(vel) < 0.05:
    vel = 0

# 3. 归一化像素误差
u_norm = u_error / cx  # 更合理的误差缩放
```

### 4. 坐标校准工具

创建`coordinate_calibration.py`工具：
- 自动收集真实坐标和检测坐标
- 计算系统性偏移
- 给出校准参数建议

## 经验教训

### 1. 简单优于复杂
- 复杂算法需要精确的参数调优
- 简单算法更鲁棒，易于调试
- 渐进式改进优于激进重构

### 2. 系统性误差需要校准
- 坐标系转换常有系统性偏移
- 需要实测数据进行校准
- 校准参数应可配置

### 3. 测试驱动开发
- 每次改进都要实测验证
- 保留多个版本便于对比
- 建立性能基准测试

## 结论

v10.1的失败提醒我们：
1. **不要过度优化**：先确保基础功能正确
2. **逐步改进**：每次只改进一个方面

4. **保持简单**：复杂不等于更好
