# v11.3.5 位置控制实现

**日期**: 2025-10-16  
**版本**: v11.3.5  
**作者**: AI Assistant

## 📋 架构更新

根据用户要求，采用类似`simple_waypoint_navigator.py`的位置控制方式，而不是速度控制。

## 🎯 核心变化

### 1. waypoint_mission.py
- **控制方式**: 直接发布PositionTarget位置目标
- **发布话题**: `/{vehicle_ns}/mavros/setpoint_raw/local`
- **控制模式**: 位置控制（FRAME_LOCAL_NED）
- **关键代码**:
```python
def _create_position_target(self, x, y, z, yaw=None):
    """创建位置目标消息"""
    cmd = PositionTarget()
    cmd.coordinate_frame = PositionTarget.FRAME_LOCAL_NED
    
    # 使用位置控制
    cmd.type_mask = (
        PositionTarget.IGNORE_VX | PositionTarget.IGNORE_VY | PositionTarget.IGNORE_VZ |
        PositionTarget.IGNORE_AFX | PositionTarget.IGNORE_AFY | PositionTarget.IGNORE_AFZ |
        PositionTarget.IGNORE_YAW_RATE
    )
    
    cmd.position.x = x
    cmd.position.y = y
    cmd.position.z = z
```

### 2. mission_controller.py
- **职责简化**: 只负责起飞控制和追踪命令转发
- **起飞控制**: 使用位置控制
- **追踪转发**: 保持速度控制（TwistStamped）
- **不再转发航点命令**: waypoint_mission直接发布到MAVROS

## 📊 控制架构

```
航点控制流程：
waypoint_mission ─(PositionTarget)─> MAVROS

追踪控制流程：
target_tracker ─(Twist)─> mission_controller ─(TwistStamped)─> MAVROS

起飞控制流程：
mission_controller ─(PositionTarget)─> MAVROS
```

## 🆚 位置控制 vs 速度控制

| 特性 | 位置控制 | 速度控制 |
|-----|---------|---------|
| 精度 | 高 | 中 |
| 响应速度 | 慢 | 快 |
| 轨迹平滑度 | 高 | 取决于算法 |
| 适用场景 | 航点导航 | 动态追踪 |
| PX4内部处理 | 位置环+速度环 | 仅速度环 |

## ✅ 优势

1. **更精确的航点到达**: PX4内部的位置控制器会自动处理减速和精确定位
2. **更平滑的轨迹**: 避免了速度控制的突变
3. **简化的逻辑**: 不需要复杂的速度计算和PID控制
4. **减少抖动**: 位置控制器内部有更好的滤波和平滑处理

## 🔧 参数配置

### waypoint_mission参数
- `waypoint_reached_threshold`: 0.5米（到达判定阈值）
- `position_hold_time`: 0.5秒（航点停留时间）

### PositionTarget配置
- **坐标系**: FRAME_LOCAL_NED（ENU坐标系）
- **控制掩码**: 忽略速度、加速度和偏航角速度
- **偏航角**: 自动计算朝向下一个航点

## 📝 测试要点

1. **位置精度**: 检查是否精确到达航点位置
2. **轨迹平滑性**: 观察飞行轨迹是否平滑
3. **模式切换**: 验证追踪/航点切换是否正常
4. **响应时间**: 位置控制可能比速度控制响应慢

## 🚀 使用说明

系统启动后：
1. mission_controller负责起飞到3米
2. waypoint_mission接管，使用位置控制飞向航点
3. 检测到人时，target_tracker发送速度命令
4. mission_controller转发追踪速度命令

## 💡 注意事项

1. **位置控制延迟**: 位置控制响应比速度控制慢，这是正常的
2. **PX4参数调优**: 可能需要调整PX4的MPC_XY_P等位置控制参数
3. **航点间距**: 位置控制更适合较大间距的航点（>5米）
4. **高度控制**: 始终使用位置控制，更安全稳定

## 🎉 总结

v11.3.5实现了混合控制架构：
- **航点导航**: 使用位置控制，确保精确性
- **人体追踪**: 使用速度控制，确保响应性
- **架构清晰**: 每个模块职责明确，易于维护

这种设计兼顾了精确性和灵活性，是一个理想的解决方案。
