# v11.3.8 追踪控制修复

**日期**: 2025-10-16  
**版本**: v11.3.8  
**作者**: AI Assistant

## 🐛 问题描述

用户反馈：target_tracker发布了速度命令，但无人机不动。

## 🔍 问题分析

经过分析发现以下问题：

1. **waypoint_mission的控制回调被阻塞**
   - _control_callback检查mission_active，在追踪模式下会直接返回
   - 导致追踪命令无法转发

2. **OFFBOARD模式维持问题**
   - 在航点模式下，waypoint_mission会发布位置命令维持OFFBOARD
   - 但mission_controller在航点模式下没有发送任何命令
   - 可能导致OFFBOARD模式退出

## 🔧 解决方案

### 1. 修复waypoint_mission控制回调
```python
def _control_callback(self, event):
    """控制回调 - 20Hz"""
    # 移除mission_active检查，允许在追踪模式下也能转发命令
```

### 2. 增强mission_controller的OFFBOARD维持
```python
elif self.flight_mode == "WAYPOINT":
    # 航点模式下也需要保持OFFBOARD，发送当前位置
    if self.current_position:
        self._send_position_setpoint(
            self.current_position.x,
            self.current_position.y,
            self.current_position.z
        )
```

### 3. 追踪模式下的零速度处理
```python
if self.current_cmd:
    # 发送追踪命令
else:
    # 没有追踪命令时，发送零速度保持OFFBOARD模式
```

### 4. 添加调试日志
- mission_controller显示收到的追踪命令
- 显示发布到MAVROS的速度命令
- 警告信息帮助诊断问题

## 📊 完整控制流程

```
1. 速度命令发布：
   target_tracker → /drone_{id}/target_tracker/cmd_vel

2. 命令转发：
   waypoint_mission (20Hz) → /drone_{id}/tracking_control

3. MAVROS发布：
   mission_controller (20Hz) → /{vehicle}/mavros/setpoint_velocity/cmd_vel

4. OFFBOARD维持：
   - 追踪模式：持续发送速度命令（或零速度）
   - 航点模式：mission_controller发送位置保持
```

## ✅ 关键修复

1. **移除阻塞条件**：waypoint_mission不再因mission_active而阻塞
2. **OFFBOARD维持**：所有模式下都持续发送命令
3. **零速度处理**：无命令时发送零速度而非不发送
4. **调试增强**：更多日志帮助诊断问题
