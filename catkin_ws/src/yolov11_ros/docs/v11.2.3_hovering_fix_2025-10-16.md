# v11.2.3 航点悬停抖动修复 - 2025年10月16日

## 问题描述

用户反馈：无人机在航点任务中原地抖动，即使只执行航点任务也会抖动

## 问题分析

经过深入分析，发现以下问题：

1. **第一个航点问题**
   - 第一个航点是(0,0,3)，这通常就是无人机起飞位置
   - 无人机会一直尝试精确到达这个点，导致不断微调

2. **速度控制问题**
   - 在0.3-1.0米范围内，速度是0.5 m/s，对于如此短距离太快
   - 容易产生超调，导致在0.3米边界附近振荡

3. **偏航控制问题**
   - 即使XY速度为0，偏航调整仍可能导致位置变化
   - 在目标点附近的偏航调整可能引起不必要的移动

## 解决方案

### 1. 优化近距离速度控制

```python
# 修改前：0.3-1.0米统一0.5 m/s
elif distance > 0.3:
    vx = 0.5 * math.cos(yaw_error)
    vy = 0.5 * math.sin(yaw_error)

# 修改后：分段减速
elif distance > 0.5:
    # 0.5-1.0米：0.3 m/s
    vx = 0.3 * math.cos(yaw_error)
    vy = 0.3 * math.sin(yaw_error)
elif distance > 0.3:
    # 0.3-0.5米：0.15 m/s（极慢）
    vx = 0.15 * math.cos(yaw_error)
    vy = 0.15 * math.sin(yaw_error)
```

### 2. 自动跳过起飞位置的航点

```python
# 在接收航点时检查第一个航点
if self.current_pose and len(waypoints) > 0:
    first_wp = waypoints[0]
    dx = first_wp['x'] - self.current_pose.position.x
    dy = first_wp['y'] - self.current_pose.position.y
    dz = first_wp['z'] - self.current_pose.position.z
    dist = math.sqrt(dx*dx + dy*dy + dz*dz)
    
    if dist < 1.0:  # 如果第一个航点在1米内，跳过它
        self.current_waypoint_idx = 1
        rospy.loginfo(f"[航点任务] 第一个航点太近({dist:.2f}m)，跳过")
```

### 3. 优化偏航控制

```python
# 在目标点附近减小偏航控制
if distance < 0.5:
    # 在目标点附近，只做小幅度偏航调整
    if abs(yaw_error) > 0.3:
        yaw_rate = yaw_error * 0.3  # 最大0.2 rad/s
    else:
        yaw_rate = 0.0  # 偏航误差很小时不调整
```

## 关键改进

1. **分段速度控制**
   - 1.0米以外：正常巡航速度
   - 0.5-1.0米：0.3 m/s
   - 0.3-0.5米：0.15 m/s
   - 0.3米以内：停止

2. **智能航点管理**
   - 自动检测并跳过距离起飞位置太近的航点
   - 避免无人机在原地打转

3. **精细偏航控制**
   - 在目标点附近减小偏航控制增益
   - 避免偏航调整引起的位置偏移

## 参数调整建议

如果还有抖动，可以考虑：
1. 增大航点到达阈值到0.5米
2. 进一步减小近距离速度
3. 增加死区范围

## 测试建议

1. 观察无人机是否跳过第一个航点
2. 接近航点时速度应该明显减慢
3. 到达航点后应该稳定悬停，无抖动
