# 地图道路结构分析报告 

## 🗺️ 地图总体概况 

 - **研究样本数量**：17张地图 
 - **道路构成**：每张地图包含**3条**主要道路 
   - 固定边界道路（1条） 
   - 不确定位置的主路（1条） 
   - 不确定位置的短路（1条） 

## 🛣️ 道路结构详解 

### 1. 固定边界道路 
**所有17张地图完全一致** 

 - **外圈边界**：由坐标围成的矩形区域 
   - `x = -45` 到 `x = 110` 
   - `y = -45` 到 `y = 45` 
 - **固定直路**：`x = -15` 的垂直道路 
   - **范围**：`-45 ≤ y ≤ 45` 
   - **特征**：贯穿整个地图南北方向 

### 2. 不确定主路（长道路） 
**三种可能配置**： 

| 类型 | 方程 | 出现概率 | 数量 | 
|------|------|----------|------| 
| 类型① | `y = 0` | `5/17` ≈ 29.4% | 5张 | 
| 类型② | `y = -10` | `6/17` ≈ 35.3% | 6张 | 
| 类型③ | `y = 11` | `6/17` ≈ 35.3% | 6张 | 

**特征**： 
 - 均为水平道路 
 - 贯穿东西方向 
 - 概率分布相对均匀 

### 3. 不确定短路 
**七种可能配置**： 

#### 垂直道路类型： 
 - **类型①**：`x = 45` 
 - **类型②**：`x = 60` 
 - **类型⑦**：`x = 30` 

#### 斜向道路类型： 
 - **类型③**：从 `(36, -45)` 到 `(54, 45)` ↗️ 
 - **类型④**：从 `(56, -45)` 到 `(74, 45)` ↗️  
 - **类型⑤**：从 `(56, 45)` 到 `(74, -45)` ↘️ 
 - **类型⑥**：从 `(36, 45)` 到 `(54, -45)` ↘️ 

## 📊 道路组合分析 

### 配置空间 
 - **主路选择**：3种可能 
 - **短路选择**：7种可能 
 - **理论组合数**：3 × 7 = 21种 
 - **实际样本数**：17张地图 

### 观察结论 
 1. **固定元素稳定**：外圈和`x=-15`道路是所有地图的共同基础 
 2. **主路偏好均衡**：三种主路配置出现频率相近 
 3. **短路多样性**：提供了地图的主要变化来源 
 4. **斜路对称性**：斜向道路成对出现，形成对称布局
