# 追踪控制修复 - 快速总结

## 🚨 问题现象
- ✅ 左右控制反向？**不是！**符号是对的（负号）
- ❌ **真正问题**：偏航增益过大**100倍**，导致剧烈抖动
- ❌ 无法稳定保持检测框在图像中心

## 🔍 根本原因

### 错误的增益计算
```python
# ❌ 错误（v10.1.2-simplified）
Kp_yaw = 100.0 / box_height  # = 0.625 (当box_height=160)
yaw_rate = -Kp_yaw * u_offset
# 结果：增益0.625，比正确值大100倍！
```

### 正确的增益（plan3）
```python
# ✅ 正确（plan3_optimized）
yaw_gains = {
    'very_close': 0.0012,  # |u| < 80px
    'close': 0.0025,       # 80-150px
    'medium': 0.0040,      # 150-220px
    'far': 0.0060          # >220px
}
yaw_rate = -u_offset * yaw_gain  # 增益0.0012-0.006
```

**差异：0.625 vs 0.0012-0.006 = 104-521倍！**

## ✅ 修复内容

### 1. 偏航控制
- ✅ 改用分级增益（0.0012-0.006）
- ✅ 添加平滑滤波（alpha=0.30）
- ✅ 死区±10px

### 2. 距离控制
- ✅ 改用box_size面积（width × height）
- ✅ 理想值1067 px²（3米）

### 3. 横向速度
- ✅ 禁用（vy=0）
- ✅ 完全依赖偏航对齐

## 📊 效果对比

| 指标 | 修复前 | 修复后 |
