# 多无人机协同追踪系统 - 快速启动指南

## 🚀 5分钟快速上手

### 步骤1：编译消息定义（首次使用）
```bash
cd E:\robocup2025\catkin_ws
catkin_make --pkg yolov11_ros_msgs
source devel/setup.bash
```

### 步骤2：验证消息
```bash
rosmsg show TargetRequest
rosmsg show TargetResponse
rosmsg show TargetHeartbeat
rosmsg show CoordinatorStatus
```

### 步骤3：启动PX4仿真
```bash
cd E:\robocup2025\PX4_Firmware
make px4_sitl_default gazebo
```

### 步骤4：启动多无人机系统
```bash
# 新终端
cd E:\robocup2025\catkin_ws
source devel/setup.bash
roslaunch yolov11_ros multi_drone_system.launch num_drones:=6
```

### 步骤5：观察协调器工作
```bash
# 新终端 - 查看协调器状态
rostopic echo /target_coordinator/status

# 新终端 - 查看追踪请求
rostopic echo /target_coordinator/request

# 新终端 - 查看追踪响应
rostopic echo /target_coordinator/response
```

## 📊 预期行为

### 场景1：单个蓝色目标
1. UAV0检测到蓝色目标
2. UAV0请求追踪 → 协调器批准
3. UAV0开始追踪，每秒发送心跳
4. UAV1也检测到蓝色目标
5. UAV1请求追踪 → 协调器拒绝（已被UAV0锁定）
6. UAV1继续巡航

### 场景2：红色目标
1. UAV0检测到红色目标
2. UAV0请求追踪 → 协调器批准
3. UAV1也检测到红色目标
4. UAV1请求追踪 → 协调器批准（红色允许多机）
5. UAV0和UAV1同时追踪红色目标

## 🔍 调试技巧

### 查看所有协调器话题
```bash
rostopic list | grep coordinator
```

### 实时监控协调器日志
```bash
rosnode list | grep coordinator
rosnode info /target_coordinator
```

### 手动发送测试请求
```bash
# UAV0请求追踪蓝色
rostopic pub /target_coordinator/request yolov11_ros_msgs/TargetRequest \
  "{drone_id: 0, target_color: 'blue', timestamp: now}"

# UAV1请求追踪蓝色（应该被拒绝）
rostopic pub /target_coordinator/request yolov11_ros_msgs/TargetRequest \
  "{drone_id: 1, target_color: 'blue', timestamp: now}"
```

### 手动发送心跳
```bash
# 发送追踪心跳
rostopic pub /target_coordinator/heartbeat yolov11_ros_msgs/TargetHeartbeat \
  "{drone_id: 0, target_color: 'blue', is_tracking: true, timestamp: now}"

# 发送停止心跳
rostopic pub /target_coordinator/heartbeat yolov11_ros_msgs/TargetHeartbeat \
  "{drone_id: 0, target_color: 'blue', is_tracking: false, timestamp: now}"
```

## ⚠️ 常见问题

### Q1: 消息类型未找到
**错误**: `ERROR: Cannot load message class for [yolov11_ros_msgs/TargetRequest]`

**解决**:
```bash
cd E:\robocup2025\catkin_ws
catkin_make --pkg yolov11_ros_msgs
source devel/setup.bash
```

### Q2: 协调器未启动
**现象**: 无人机不追踪目标

**检查**:
```bash
rosnode list | grep target_coordinator
```

**解决**: 检查launch文件是否包含协调器节点

### Q3: 多架无人机追踪同一个非红色目标
**现象**: 违反了协同规则

**检查**:
```bash
rostopic echo /target_coordinator/status
rostopic echo /target_coordinator/response
```

**可能原因**:
1. 协调器崩溃
2. 心跳未发送
3. 消息丢失
