# 简化版多无人机协同追踪系统

## 版本信息
- **版本**: v10.3.0-simple
- **日期**: 2025-10-17
- **特点**: 不需要编译新消息，直接使用String消息

---

## 核心设计

### 1. 使用现有消息类型
- **不创建新消息**：只使用`std_msgs/String`
- **不需要编译**：修改后直接运行
- **简单可靠**：减少依赖，降低复杂度

### 2. 通信机制

#### 无人机 → 协调器
- **话题**: `/drone_{id}/locked_color`
- **类型**: `std_msgs/String`
- **内容**: 
  - 锁定时：发送颜色名称（如`"blue"`）
  - 释放时：发送空字符串（`""`）

#### 协调器 → 无人机
- **话题**: `/coordinator/locked_colors`
- **类型**: `std_msgs/String`
- **内容**: `"drone_0:blue,drone_1:green,drone_2:white"`
- **频率**: 2Hz（每0.5秒）

## 工作流程

### 场景1：UAV0发现蓝色目标
```
1. UAV0检测到蓝色目标
2. UAV0检查：蓝色不在locked_colors中 ✅
3. UAV0发布：/drone_0/locked_color = "blue"
4. 协调器收到，更新状态
5. 协调器广播：/coordinator/locked_colors = "drone_0:blue"
6. UAV0开始追踪蓝色目标
```

### 场景2：UAV1也发现蓝色目标
```
1. UAV1检测到蓝色目标
2. UAV1收到：/coordinator/locked_colors = "drone_0:blue"
3. UAV1检查：蓝色在locked_colors中 ❌
4. UAV1跳过，继续巡航
5. 日志：⚠️ 无人机1: blue目标已被其他无人机锁定，跳过
```

### 场景3：红色目标（允许多机追踪）
```
1. UAV0检测到红色目标
2. UAV0检查：红色 != 'red'? 否，可以追踪 ✅
3. UAV0发布：/drone_0/locked_color = "red"
4. UAV1也检测到红色目标
5. UAV1检查：红色 != 'red'? 否，可以追踪 ✅
6. UAV1发布：/drone_1/locked_color = "red"
7. 两架无人机同时追踪红色目标
```

## 关键代码

### human_tracker.py 中的协调逻辑

```python
# 检查目标是否被其他无人机锁定（红色除外）
target_color = best_target.Class
can_track = True

if target_color != 'red' and target_color in self.locked_colors:
    can_track = False
    rospy.loginfo_throttle(5.0, f"⚠️ 无人机{self.drone_id}: {target_color}目标已被其他无人机锁定，跳过")

# 发现新目标且可以追踪
if can_track and (self.flight_mode != "TRACKING" or self.current_target_color != target_color):
    self.current_target_color = target_color
    self.my_locked_color = target_color
    # 发布锁定信息
    self.my_lock_pub.publish(String(data=target_color))
    self._start_tracking()
```

### simple_coordinator.py 核心逻辑
```python
def _update_lock(self, msg, drone_id):
    """更新无人机的锁定状态"""
    if msg.data:
        self.drone_locks[drone_id] = msg.data
        rospy.loginfo(f"🔒 无人机{drone_id} 锁定: {msg.data}")
    else:
        if drone_id in self.drone_locks:
            color = self.drone_locks[drone_id]
            del self.drone_locks[drone_id]
            rospy.loginfo(f"🔓 无人机{drone_id} 释放: {color}")

def _publish_status(self, event):
    """发布全局锁定状态"""
    locks = [f"drone_{did}:{color}" for did, color in self.drone_locks.items()]
    status_str = ','.join(locks)
    self.status_pub.publish(String(data=status_str))
```
