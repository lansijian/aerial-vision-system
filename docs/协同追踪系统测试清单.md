### ✅ 测试2：单机追踪请求测试

**步骤**：
```bash
# 终端1：启动协调器
rosrun yolov11_ros target_coordinator.py

# 终端2：发送追踪请求（蓝色目标）

  "{drone_id: 0, target_color: 'blue', timestamp: now}"

# 终端3：监听响应
rostopic echo /target_coordinator/response
```

**验证点**：
- [ ] 协调器收到请求
- [ ] 协调器批准追踪（approved: true）
- [ ] 响应原因为"目标未被锁定"
- [ ] 状态话题显示蓝色被UAV0锁定

**预期响应**：
```yaml

target_color: "blue"
approved: True
reason: "目标未被锁定"
timestamp: ...
```

### ✅ 测试5：心跳机制测试

**步骤**：
```bash
# 终端1：UAV0请求追踪蓝色
rostopic pub /target_coordinator/request yolov11_ros_msgs/TargetRequest \
  "{drone_id: 0, target_color: 'blue', timestamp: now}"

# 终端2：发送心跳（每秒一次，持续3次）
rostopic pub /target_coordinator/heartbeat yolov11_ros_msgs/TargetHeartbeat \
  "{drone_id: 0, target_color: 'blue', is_tracking: true, timestamp: now}"

# 等待5秒（停止发送心跳）

# 终端3：UAV1请求追踪蓝色
rostopic pub /target_coordinator/request yolov11_ros_msgs/TargetRequest \
  "{drone_id: 1, target_color: 'blue', timestamp: now}"
```

**验证点**：
- [ ] 前3秒UAV1请求被拒绝
- [ ] 5秒后（心跳超时）UAV1请求被批准
- [ ] 协调器日志显示"锁定超时，自动释放"

## Bug检查清单

### ✅ 边界条件
- [ ] 无效颜色请求被拒绝
- [ ] drone_id超出范围的请求被正确处理
- [ ] 空消息不会导致崩溃
- [ ] 重复请求不会导致重复锁定

### ✅ 并发安全
- [ ] 多个请求同时到达时，只有一个被批准
- [ ] 心跳和请求同时到达时，状态一致
- [ ] 线程安全（使用了lock_mutex）

### ✅ 容错性
- [ ] 协调器崩溃后重启，状态重置
- [ ] 无人机崩溃后，心跳超时自动释放
- [ ] 网络抖动不影响系统运行
