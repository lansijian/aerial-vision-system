# 6机Launch格式统一说明

## 修改时间
2025年1月17日

## 修改内容

已将 `multi_drone_system.launch` 中所有6架无人机的配置格式统一为标准格式，与UAV0和UAV1保持一致。

## 格式特点

### 1. **清晰的注释分组**
所有参数按功能分组，便于现场调试：
```xml
<!-- 基础参数 -->
<!-- 云台参数 -->
<!-- 坐标系偏移补偿 -->
<!-- ========== 追踪优化参数（方便现场调） ========== -->
<!-- Kalman滤波 -->
<!-- 自适应偏航控制 -->
<!-- 前后距离控制（框高法） -->
<!-- 高度控制（增强保持力度） -->
<!-- 速度饱和限制 -->
```

### 2. **坐标系偏移补偿（重点）**

每架无人机都有明确的坐标系偏移补偿参数，对应官方起飞位置：

| 无人机 | 起飞位置 (x, y, z) | spawn_offset_x | spawn_offset_y |
|--------|-------------------|----------------|----------------|
| UAV0   | (-17, -3, 1)      | -17.0          | -3.0           |
| UAV1   | (-14, -3, 1)      | -14.0          | -3.0           |
| UAV2   | (-17,  0, 1)      | -17.0          |  0.0           |
| UAV3   | (-14,  0, 1)      | -14.0          |  0.0           |
| UAV4   | (-17,  3, 1)      | -17.0          |  3.0           |
| UAV5   | (-14,  3, 1)      | -14.0          |  3.0           |

**作用说明：**
- 这些偏移参数用于补偿无人机的实际起飞位置
- 在追踪算法中，目标位置需要减去这个偏移量才能得到正确的相对位置
- 确保所有无人机在追踪时使用统一的世界坐标系

### 3. **三模块架构**
每架无人机都包含完整的三模块：
1. **drone_controller** - 主控制器（起飞、模式切换）
2. **waypoint_navigator** - 航点导航器（位置控制）
3. **human_tracker** - 人体追踪器（速度控制 + Kalman滤波）

### 4. **云台控制**
每架无人机都有独立的云台控制节点：
```xml
<!-- 云台控制 -->
<group if="$(arg enable_gimbal_control)">
  <node name="gimbal_control_typhoon_h480_X" ... />
</group>
```

## 优势

1. **格式统一** - 所有无人机配置一致，便于维护
2. **注释清晰** - 参数分组明确，现场调试方便
3. **坐标补偿** - 每架无人机都有正确的起飞位置偏移
4. **易于调整** - 追踪参数集中在一起，方便现场优化

## 使用建议

现场调试时，如需修改追踪参数：
1. 只需修改 `<!-- ========== 追踪优化参数（方便现场调） ==========` 部分
2. 所有无人机使用相同参数，确保行为一致
3. 不要修改坐标系偏移补偿参数，除非起飞位置改变

## 注意事项

⚠️ **坐标系偏移补偿非常重要！**
- 如果起飞位置改变，必须同步更新 `spawn_offset_x` 和 `spawn_offset_y`
- 这两个参数直接影响追踪算法的目标定位精度
- 错误的偏移会导致无人机追踪时位置偏差
