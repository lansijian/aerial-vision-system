## 🔍 起飞位置布局（俯视图）

```
        Y轴
         ↑
         |
    3 ---|--- UAV4(-17,3)  UAV5(-14,3)
         |
    0 ---|--- UAV2(-17,0)  UAV3(-14,0)
         |
   -3 ---|--- UAV0(-17,-3) UAV1(-14,-3)  ✅ 当前配置
         |
         +------------------------→ X轴
       -17  -14   0
```

### 设计理念
- **X轴**: 两列布局 (`-17` 和 `-14`)，间距 3米
- **Y轴**: 三排布局 (`-3`, `0`, `3`)，间距 3米
- **Z轴**: 统一高度 `1米`（地面起飞）
- **优势**: 
  - ✅ 避免碰撞（最小间距3米）
  - ✅ 便于扩展（6机协同）
  - ✅ 符合官方标准

## 📝 注意事项

1. **坐标系**: 使用 ENU 坐标系（East-North-Up）
   - X轴: 东（正方向）
   - Y轴: 北（正方向）
   - Z轴: 上（正方向）

2. **航点文件**: 
   - `initial_position` 必须与 launch 文件的起飞位置一致
   - 已验证 ✅ 当前配置正确

3. **扩展到6机**: 
   - 参考官方 `robocup_base.launch` 的配置
   - 保持端口递增规则不变
