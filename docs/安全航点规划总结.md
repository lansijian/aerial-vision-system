## 追踪完成后返回最近航点

### 功能说明
当无人机追踪目标完成后，会自动：
1. 计算当前位置
2. 找到最近的航点
3. 返回该航点继续巡逻

### 实现方式
```python
def find_nearest_waypoint(current_x, current_y, waypoints):
    """找到距离当前位置最近的航点索引"""
    min_dist = float('inf')
    nearest_idx = 0
    
    for i, wp in enumerate(waypoints):
        wp_x = wp['y']  # 注意：已互换
        wp_y = wp['x']
        dist = ((current_x - wp_x)**2 + (current_y - wp_y)**2)**0.5
        if dist < min_dist:
            min_dist = dist
            nearest_idx = i
    
    return nearest_idx
```
