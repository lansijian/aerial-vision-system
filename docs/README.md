- 航点设计原则
- 坐标系说明

**关键点**:
- ⚠️ JSON中x和y已互换
- 所有航点在道路上
- 避开建筑物区域

### 创建新文档

如果需要创建新文档，请遵循：

1. **文件命名**: 使用中文或英文，描述清晰
2. **Markdown格式**: 统一使用Markdown语法
3. **结构清晰**: 包含目录、小节标题
4. **代码示例**: 使用代码块，注明语言
5. **截图**: 放在 `docs/images/` 目录
6. **更新索引**: 在本README中添加链接
