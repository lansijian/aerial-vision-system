# 6机起飞问题修复说明

## 问题描述
剩下4架无人机（UAV2-5）没有起飞

## 问题原因
**航点文件路径错误**

multi_drone_system.launch中配置的航点文件路径为：
```xml
<param name="waypoint_file" value="waypoints/waypoints_drone_X.json" />
```

但实际航点文件位于：
```
e:\robocup2025\catkin_ws\src\yolov11_ros\scripts\waypoints\waypoints_drone_X.json
```

## 解决方案

### 修改内容
将所有6架无人机的航点文件路径从 `waypoints/` 修改为 `scripts/waypoints/`

**修改文件：** `multi_drone_system.launch`

**修改前：**
```xml
<param name="waypoint_file" value="waypoints/waypoints_drone_0.json" />
<param name="waypoint_file" value="waypoints/waypoints_drone_1.json" />
<param name="waypoint_file" value="waypoints/waypoints_drone_2.json" />
<param name="waypoint_file" value="waypoints/waypoints_drone_3.json" />
<param name="waypoint_file" value="waypoints/waypoints_drone_4.json" />
<param name="waypoint_file" value="waypoints/waypoints_drone_5.json" />
```

**修改后：**
```xml
<param name="waypoint_file" value="scripts/waypoints/waypoints_drone_0.json" />
<param name="waypoint_file" value="scripts/waypoints/waypoints_drone_1.json" />
<param name="waypoint_file" value="scripts/waypoints/waypoints_drone_2.json" />
<param name="waypoint_file" value="scripts/waypoints/waypoints_drone_3.json" />
<param name="waypoint_file" value="scripts/waypoints/waypoints_drone_4.json" />
<param name="waypoint_file" value="scripts/waypoints/waypoints_drone_5.json" />
```

### 路径解析逻辑
drone_controller.py 中的路径解析：
```python
self.waypoint_file = rospy.get_param('~waypoint_file', 
                                    f'waypoints/waypoints_drone_{self.drone_id}.json')
```

ROS会自动在package路径下查找，因此：
- `scripts/waypoints/waypoints_drone_X.json` 
- 解析为：`$(find yolov11_ros)/scripts/waypoints/waypoints_drone_X.json`
