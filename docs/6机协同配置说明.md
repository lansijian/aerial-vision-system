## 启动方式

### 1. 启动Gazebo仿真（6架无人机）
```bash
roslaunch px4 robocup.launch
```

### 2. 启动多机控制系统

**启动全部6架（默认）：**
```bash
roslaunch yolov11_ros multi_drone_system.launch
```

**启动指定数量（2-6架）：**
```bash
roslaunch yolov11_ros multi_drone_system.launch num_drones:=2
roslaunch yolov11_ros multi_drone_system.launch num_drones:=4
```

## 关键修改

### robocup.launch 主要变更：

1. **verbose参数**：`true` → `false`（减少日志输出）
2. **新增UAV2-5配置**：完整的4架无人机配置
3. **起飞位置**：严格按照官方标准
4. **模型文件**：每架使用独立的sdf文件

✅ 起飞位置与官方robocup_base.launch完全一致  
✅ 端口映射规则正确（避免冲突）  
✅ 模型文件已存在  
✅ 航点文件已配置  
✅ 追踪算法已优化（紧急后退+高度限制）

## 注意事项

1. **端口冲突**：确保所有端口不与其他程序冲突
2. **资源占用**：6架无人机对CPU/GPU要求较高
3. **Gazebo性能**：建议关闭verbose减少日志
4. **模型加载**：首次启动可能较慢，等待所有模型加载完成

## 测试建议

1. 先测试2架无人机（UAV0和UAV1）
2. 确认正常后再启动全部6架
3. 观察各无人机是否正确起飞到指定位置
4. 检查MAVROS连接是否正常
5. 验证航点导航和追踪功能
