# 6机解锁问题修复说明

## 问题描述

**现象：** UAV0和UAV1能正常起飞，但UAV2-5无法切换到OFFBOARD模式，导致解锁失败。

**错误日志：**
```
[ERROR] ❌ 无人机2 OFFBOARD模式设置失败
[ERROR] ❌ 无人机3 OFFBOARD模式设置失败
[ERROR] ❌ 无人机4 OFFBOARD模式设置失败
[ERROR] ❌ 无人机5 OFFBOARD模式设置失败
```

## 根本原因

**PX4安全参数限制** - PX4默认只允许前2架无人机在没有遥控器的情况下进入OFFBOARD模式并解锁。

这是PX4的安全机制，需要显式设置参数来允许更多无人机使用OFFBOARD模式。

## 解决方案

### 方案1：自动设置（推荐）✅

已在 `multi_drone_system.launch` 中集成自动参数设置功能。

**工作原理：**
1. 启动时自动运行 `set_px4_params.py` 脚本
2. 脚本等待3秒后开始配置
3. 为所有6架无人机设置PX4参数
4. 配置完成后自动退出

**使用方法：**
```bash
# 1. 启动Gazebo仿真
roslaunch px4 robocup.launch

# 2. 启动控制系统（会自动配置PX4参数）
roslaunch yolov11_ros multi_drone_system.launch
```

**日志输出：**
```
🔧 PX4参数自动设置 - 允许OFFBOARD模式解锁
   配置无人机数量: 6
--- 配置无人机 0 (typhoon_h480_0) ---
  ✅ typhoon_h480_0: COM_RCL_EXCEPT = 4
  ✅ typhoon_h480_0: NAV_RCL_ACT = 0
...
✅ 所有 6 架无人机参数设置完成！
```

### 方案2：手动设置

如果自动设置失败，可以手动运行脚本：

```bash
# 确保Gazebo和MAVROS已启动
roslaunch px4 robocup.launch

# 在新终端运行
cd ~/catkin_ws/src/yolov11_ros/scripts
python3 set_px4_params.py
```

## 关键参数说明

| 参数名 | 设置值 | 说明 |
|--------|--------|------|
| `COM_RCL_EXCEPT` | 4 | 允许OFFBOARD模式（即使没有遥控器）<br>0=禁用, 4=允许OFFBOARD |
| `NAV_RCL_ACT` | 0 | RC失联时的行为<br>0=禁用保护（仿真环境无RC） |
| `NAV_DLL_ACT` | 0 | 数据链路失联时的行为<br>0=禁用保护 |
| `COM_OF_LOSS_T` | 5.0 | OFFBOARD失联超时时间（秒）<br>超时后触发失联保护 |

## 技术细节

### 为什么UAV0和UAV1能起飞？

PX4在仿真模式下对前2架无人机（ID 0和1）有特殊处理：
- 自动允许OFFBOARD模式
- 降低安全检查严格度
- 便于开发测试

但从UAV2开始，需要显式设置参数。

### 参数设置时机

脚本在launch文件中配置了3秒延迟：
```xml
<node ... launch-prefix="bash -c 'sleep 3; $0 $@' ">
```

这确保：
1. ✅ MAVROS服务已启动
2. ✅ PX4实例已初始化
3. ✅ 参数服务可用

### 验证参数设置

检查参数是否生效：
```bash
# 查看无人机2的参数
rosrun mavros mavparam get -n /typhoon_h480_2/mavros COM_RCL_EXCEPT

# 应该返回: 4
```

## 故障排除

### 问题1：参数设置失败

**症状：**
```
⚠️ typhoon_h480_2: COM_RCL_EXCEPT 设置失败
```

**原因：** MAVROS服务未启动或PX4未连接

**解决：**
1. 检查Gazebo是否正常运行
2. 检查MAVROS连接状态：
   ```bash
   rostopic echo /typhoon_h480_2/mavros/state -n 1
   ```
3. 增加等待时间（修改launch文件中的sleep值）

### 问题2：部分无人机设置成功

**症状：**
```
⚠️ 只有 4/6 架无人机参数设置成功
```

**原因：** 系统资源不足，部分PX4实例启动慢

**解决：**
1. 手动重新运行脚本
2. 或只启动成功的无人机数量：
   ```bash
   roslaunch yolov11_ros multi_drone_system.launch num_drones:=4
   ```

### 问题3：参数设置后仍无法解锁

**症状：** 参数设置成功但仍然OFFBOARD失败

**原因：** 可能是setpoint发布频率不足

**解决：**
1. 检查drone_controller日志
2. 确认setpoint发布频率 >2Hz
3. 检查MAVROS连接是否稳定
